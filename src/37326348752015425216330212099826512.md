## <font color="#3333ff">減傷技能對於回血能力的影響（附計算）&nbsp;</font>Mon Oct 29 15:29:07 2012

簡單說，這是一個評價回血能力的系統，計算很簡單，也很實用，文末附上數組範例\
\
來講解用法，對此法有興趣的人可以推文討論。\
\
首先我們要先瞭解&nbsp;減傷 x ％&nbsp;（近戰減傷，遠程減傷，精英減傷等等）代表的意義才有辦法討論減傷對於回血的的效果。首先，不同的減傷（甚至是不同道具）的減傷效果是獨立計算的，比如說護腕 6％ 近戰減傷加上頭部 6％ 近戰減傷並不等於總和 12％，而會等於11.74％ 減傷（後面會說明怎麼算出來的），這個也就是你實際在面板上看到的數字。\
\
\
舉例來說，假如你受到 1 點傷害，減傷 10％ 代表你可以擋去 1\*10％＝0.1 傷害，那麼你實際上會承受的傷害會是總傷害 1 點扣去少承受的 0.1 點傷害，最後得到 0.9 傷害。那麼多次傷害又是如何判定呢？ 假設你有兩個 10％ 減傷的物品，第一個物品讓你實際傷害變成 0.9，第二個物品則是讓你受到的傷害變成 (1-10％) 被，也就是0.9\*0.9＝0.81點傷害，也就是最後實際得到的傷害，這等效於一個 19％ 減傷效果的物品，因為一個19％ 減傷相當於可以擋去 1\*19％＝0.19 傷害，實際傷害也是 1-0.19＝0.81\
\
\
假如獨立的減傷的效果為&nbsp;x1、x2、x3&nbsp;.... （因為是百分比，都是大於零，小於一的數）\
\
\
\
\
總和的減傷效果 x 會滿足等式&nbsp;&nbsp;&nbsp;1-x&nbsp;= (1-x1)(1-x2)(1-x3).....\
\
\
\
x&nbsp;= 1- (1-x1)(1-x2)(1-x3).....，若&nbsp;x1、x2&nbsp;極小時，x&nbsp;= 1-1+x1+x2+x1\*x2 \~&nbsp;x1&nbsp;+&nbsp;x2\
\
\
這個時候才能近似成直接相加。某些情況比如說不朽之王套裝與雷神之力同時裝備時，會發現面板計算出來的近戰減傷遠小於個別部位提供的和，這代表你的減傷看起來有邊際效應。事實上這個邊際效應只是錯覺，也會出現在抗性和護甲上，因為抗甲本來就是減傷的一種，值得注意的地方在於計算等效血量的時候並不會有邊際效應，不過這不是這篇想要討論的重點，所以接著我們直接討論回血效果。\
\
\
假設你原本每秒可回 100 血，你在一秒內受到 100 點傷害，擁有 10％ 減傷，那麼你實際受到的傷害其實是 90 點傷害，所以說你實際上並不需要 100 點回血效果，只要 90 點秒回就能打平傷害達成鎖血。換句話說，10 ％減傷相當於將 90 點回血效果放大成 100&nbsp;點效果，換句話說我們可以把減傷 x% 看成讓回血能力增加 R 倍的物件，其中\
\
\
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;1\
R =&nbsp;&nbsp;------------- = 1 + x% - (x^2)%&nbsp;&nbsp;+ (x^3)% + ......\
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;1-x%\
\
\
\
\
我把這個&nbsp;R&nbsp;稱為減傷回血倍率\
\
\
當 x％ 遠小於 1 時，右式差不多等於 1 + x％，我們可簡單用這個數字來衡量減傷對回血的效果 。假如有多個部位提供減傷，那麼這些部位提供的總減傷回血倍率相當於個別總減傷倍率的乘積（用相同推論可得到這個結果）\
\
這個時候我們可以計算巴巴人一些常用防禦技能的回血倍率，這個數字代表你裝上它可以將原本的生命竊取或者擊回增加幾倍\
\
\
被動迷信 20％ 非物理傷害減傷 -> 1/(1-20%) = 1.25\
威嚇怒吼 20％ 減傷&nbsp;&nbsp;&nbsp;->&nbsp;&nbsp;1/(1-20%) = 1.25\
霸氣無雙 35％ 減傷&nbsp;&nbsp;&nbsp;->&nbsp;&nbsp;1/(1-35%) =&nbsp;1.54\
忘卻痛苦 65％ 減傷&nbsp;&nbsp;&nbsp;->&nbsp;&nbsp;1/(1-65%) = 2.86\
\
\
另外閃躲可視為不穩定的減傷源，假如不考慮總血量過低造成的死亡，長期來看閃躲率可以直接換算成減傷 ％數（關於格檔的效果會單獨用另一篇文章來說明）\
\
衝刺的 +12％ 閃躲符文 -> 1/(1-12%) = 1.14\
戰吼的 +15％ 閃避符文（不考慮）->&nbsp;&nbsp;1/(1-15%) = 1.18\
超級賽亞人的被動閃避效果 +20%&nbsp;&nbsp;->&nbsp;&nbsp;1/(1-20%) =&nbsp;1.25\
敏捷 100-500 內，每 100 點敏捷的閃避效果為 2.5％ -> 1/(1-2.5％) = 1.0256\
主屬 500 敏比 200 敏多提供 7.5% 效果 ->&nbsp;&nbsp;1/(1-7.5%) =&nbsp;1.081\
\
\
另外一些特殊物品提供的減傷也值得說明\
\
\
不朽全套約 18％ 近戰減傷&nbsp;&nbsp;->&nbsp;&nbsp;1/(1-18%) = 1.2195\
雷神之力最高 20％ 近戰減傷 -> 1/(1-20%) = 1.25\
近戰遠程皆 6％ 減傷的護腕 -> 1/(1-6%) = 1.064\
\
\
\
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;護甲值\
至於護甲減傷減免公式為 ------------------------------------------------- ，假設護甲原本有 3000\
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;護甲值&nbsp;&nbsp;＋ Monster Level(63)\*500\
\
\
\
那麼原始減免為 3000/(3000 + 3150) = 48.78%，\
原始回血倍率為 1/(1-48.78%) = 1.952，由此計算每隔 500 甲的原始回血倍率\
\
\
\

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;增加的倍率\

\
\
\
每 500 甲大約提供 1.05 至 1.08 的倍數，假設要計算護甲由 5000 增加 20％ 至&nbsp;6000 （戰吼效果），那麼增加的回血倍率就是 2.905/2.567 =&nbsp;&nbsp;1.13，其餘類推抗性的計算基本上乘以十倍可以套用同樣表格估算（ 500抗 ～ 5000 甲）\
\
\
看過這麼多最後你發現了嗎，減傷％數表面上看起來疊加變少了，但實際上對於回血的影響反而越大！ 基本上減傷除了提高等效血量之外，根本就是一個拉高等效生命竊取的方法\
\
\
農高 MP 究竟要多高的生竊才夠，不同玩法派別得要高手實測後才能給出一個經驗法則（比如 450 抗 5000 甲 8％ 生竊的之類），這裡引入的回血倍率不能告訴你確切的數字，卻可以從已知的站樁配置推算拔掉哪些招式，增減哪些裝可以確保你的回血能力仍足以站樁屹立不搖，甚至作為換裝的比較基準！\
\
\
\
<font color="#3333ff">範例一： 為何霸氣無雙是野蠻人神技</font>\
\
35％ 減傷可提供約 1.54 回血倍率，假如你未開招生竊原本就有6％（武器加腰帶）放完霸氣無雙當下你的生竊瞬間變成約 9％，幾乎等效於增加一個 3％ 吸血被動;假如搭配撕裂 9％ 吸血符文，相當於這 4 秒多出面板 DPS 4.5％ 的秒回，以 DPS10W 計算，幾乎多出 10W \* 4.5％ \* 0.2 = 900 秒回，對於低血量 （4\~5W），這又差不多等於激勵風采的被動（秒回 2％ 生命）\
\
你說，這能不神嗎？\
\
儘管忘卻痛苦倍率更高，卻會因為冷卻時間過長而失去實戰效果，高爆率的巴巴人很容易就靠霸氣無雙的特效刷新 CD 時間，讓將 1/2 的時間處於霸氣無雙作用的狀態，所以容易無腦站樁\
\
\
<font color="#3333ff">範例二： 腰帶從帶生竊的重腰換成帶爆傷爆率的巫異時刻可行嗎？</font>\
\
\
假設你原本有 40％ 爆率 300％ 爆傷，那麼一條 8％ 攻速，爆傷 40％ 的巫異會讓你得到 108％ 攻速 40％ 爆率&nbsp;&nbsp;340％ 爆傷。\
\
DPS = 攻速\*\[ 爆率 \* （爆傷 + 100％）+ (1-爆率)\* 100％ \]\
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;= 攻速\*\[爆率 \* 爆傷 + 1\]\
\
原本的 DPS = 1\*(1 + 40% \* 300% ) = 2.2\
新的 DPS = 1.08 \*( 1 + 40 \* 340%) = 2.55\
\
因為 DPS 與生命竊取的量成正比，所以巫異時刻的額外攻擊帶來的回血效益可視為&nbsp;2.55/2.2 = 1.16\
\
\
假設不含腰帶本身具備 3％ 回血（技能或武器自帶），腰帶帶 2.8％ 生竊；則原先的生竊為 1\*(3％ + 2.8 ％) = 5.8 %\
\
\
新的生竊為 1.16\*3% = 3.48 %\
\
這顯然不夠。那我原先必須具備多少生竊才能無痛更換巫異增加 DPS ？ 設此值為 x，1.16 \* x = 5.8%，得到 x = 5% ，代表我至少原本要有 5％ 生竊才 OK，這對雙手撕裂蠻非常容易僅靠武器的生竊量就達成。\
\
又或者們可以想想要補足多少回血倍率才能得到同樣得效果，令此倍率為 y\
\
1.16 \* 3% \* y = 5.8% ，得到 y = 1.67\
\
這個可以透過霸氣無雙 （1.54倍率） 與 500～1000 甲或 50～100 抗&nbsp;（1.10 \~ 1.16 倍率） 同時作用達成。\
\
\
\
<font color="#3333ff">範例三：帶 18％ 近戰減傷的雷神之力等效於多少抗的腰帶？</font>\
\
假設原本不考慮其他屬性， 18％ 減傷可以提供 1/(1-18%) = 1.22 倍率\
假如你原本有 300 抗（或 3000 甲），這差不多有&nbsp;100 抗（或 1000 甲）至150 抗（或 1500 甲）至的效果（從前文表格推算）\
\
若原本有 500 抗（或 5000 甲），那麼效果介於&nbsp;150 抗至 200 抗之間。這個基本上解釋了 1.02 甚至更久遠以前版本巴巴人流行長串之耳，暴風盾加近減的現象，在那個沒千抗萬甲農不起煉獄的年代，衝抗甲以外的高減傷物品效益相當高。\
\
\
<font color="#3333ff">範例四：&nbsp;&nbsp;巴巴人衝敏加閃避是否自找麻煩，白作工？</font>\
\
\
在敏捷換算閃躲未遞減得區域內， 100 敏相當於 2.5％ 閃躲，減傷約 1.0256，效果相當於從 5500 甲增到 5700 甲，或者從 7000 甲增到 7250 甲。對於低抗甲的人來說優勢不大，基本上算是不需要刻意追求的部份。\
\
比如說不朽手跟不朽鞋都有一種 roll 到高敏（\~150 敏）的版本，基本上不會有其他職業穿，很多追求 DPS 的巴巴人嗤之以鼻（畢竟少了一個隨機屬性），不過我穿起來等於多個 40 抗，CP 值相當高。\

## <font color="#3333ff">從減傷與回血增益談近戰職業拿盾的效益</font> &nbsp;&nbsp;Mon Oct 29 20:29:51 2012&nbsp;

劍盾蠻最大的困擾就是：我沒神裝，DPS 很低該怎麼辦？ 拿盾到底對扛怪有沒有幫助？\
\
這篇文章主要就是要來分析拿盾是否能夠應付高 MP 傷害，假如扛不住，那麼早點轉雙手或雙持比較實在 XD\
想知道古早坦蠻三神器今日要怎麼挑才合理嗎，看了這篇你就懂了\
\
\
\
本文對於回血的分析基本上沿襲\
[【攻略】減傷技能對於回血能力的影響（附計算）](http://ref.gamer.com.tw/redir.php?url=http%3A%2F%2Fforum.gamer.com.tw%2FC.php%3Fbsn%3D21400%26snA%3D200778%26tnum%3D3%26subbsn%3D3)\
\
\
首先，我們可以把格檔的概念理解成一種弱化版的閃避。閃避就好比格檔值無窮大的格檔，只要正確發動，那麼該次所受到的傷害就必須扣掉格檔值才是真正應該受到的傷害；由於閃避相當於具備無窮大的格擋值，所以不管多大的傷害都可以被吸收，因此長遠來看你受到的平均傷害幾乎等於怪物的 DPS 乘上 (1 - 閃避率)，同等閃避率的減傷效果幾乎等於同等數值的各類減傷。前幾版秘術師的堅毅護甲就效果就很像加強版的盾牌，不關單次受到多大傷害都直接扣至生命值 35％，換句話說格檔率相當於怪物發動致命一擊的頻率，格檔值為該次致命一擊扣去各種減傷再扣去生命值 35％，\
這效果 imba 的地方在於格檔值要多大就多大，遇強則強，一發動必擋掉瞬間爆發輸出（想像一下有一面盾牌把所有格檔機會都用在你可能被砍死的時候，絕對神器啊）所以後來才改成一旦致命一擊減傷後大於總生命就讓堅毅護甲失效，變相給這個盾一個格擋值上限。\
\
\
回到主題，什麼是格檔呢？ 假如我有一面 33.333％ 格檔率的盾，格檔值 5k，那麼我可以想見這個盾平均三次攻擊會幫我檔掉一次傷害，減傷幅度相當於格檔值，所以我可以試著估計不同怪物 DPS 的情況下持盾的帶來的減傷效果\
\
\
case 1. 外來傷害 DPH (Damage per Hit) 小於格檔值\
\
假設每個 hit 吃 4k 傷害，那麼我收到傷害時變序列可能長這個樣子：\
\
\
4k 4k 0&nbsp;&nbsp;4k&nbsp;&nbsp;4k&nbsp;&nbsp;4k 0&nbsp;&nbsp;0&nbsp;&nbsp;4k&nbsp;&nbsp;0&nbsp;&nbsp;4k&nbsp;&nbsp;4k&nbsp;&nbsp;4k&nbsp;&nbsp;0&nbsp;&nbsp;&nbsp;4k ........\
\
\
你會發現長期看下來有盾受到的傷害會是 4k \*（1-格檔率)，這個時候格檔率就跟減傷% 數完全一樣。所以在怪物 DPH 夠低的情況下，一顆 30％ 格檔率的盾就有30％ 減傷效果，回血倍數為 1/(1-30%) = 1.429，完全不考慮其他屬性加成，這個倍率相當於把 400 抗 4000 甲昇級成 550 抗 5500 甲，換言之不考慮盾牌本身的上千的高護甲，光是格檔率就貢獻等效上 150 抗 1500 甲的防禦強度\
\
要記得盾牌的減傷是其他減傷算完以後才計算，所以頂盾 3706-4706 的格檔值足以吃下不開 MP 的煉獄怪傷害，只要 EHP/HP 加秒回血能力夠，拿盾的蠻子就算砍不死怪，通常也死不了 ----- 除非被不吃格檔的精英元素傷害技痛宰。\
\
\
case 2. 外來傷害 DPH (Damage per Hit) 大於格檔值\
\
這個時候就悲劇了，case 1. 只是理想狀態，通常自虐想推高 MP 的劍盾蠻開始會感受\
到怪物強大的破壞力，假設盾判定前的淨傷害是 11k，那麼收到的傷害序列大概長這個\
樣子：\
\
\
10k&nbsp;&nbsp;6k&nbsp;&nbsp;10k&nbsp;&nbsp;10k&nbsp;&nbsp;&nbsp;6k&nbsp;&nbsp;10k&nbsp;&nbsp;10k&nbsp;&nbsp;6k&nbsp;&nbsp;6k&nbsp;&nbsp;10k&nbsp;&nbsp;10k&nbsp;&nbsp;10k ......\
\
\
這個時候平均傷害會是 （10k-格檔值） \*&nbsp;&nbsp;格檔率 + 10k \*(1-格檔率)= 10k - 格檔值 \* 格檔率，&nbsp;&nbsp;&nbsp;減去的傷害恰好等於格檔值 \* 格檔率\
\
有沒有發現這個攻勢長得跟爆傷爆率挺像的啊，唯一的差別在於平均格檔值大約 4206封頂。所以我們可以推算出此時盾牌的減傷% 為\
\
格檔值（BV）\* 格檔率 (BC)\
\-------------------------------------------,&nbsp;&nbsp;&nbsp;BV = Block Value,&nbsp;&nbsp;BC = Block chance\
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;怪物 DPH (DPH)\
\
\
\
case 1. 的情形就是 DPH = BV，減傷 BR 恰好等於 BV若是 DPH > BV，會得到 BR' = k \* BV，&nbsp;&nbsp;k = BC/DPH =&nbsp;&nbsp;4206/DPH&nbsp;&nbsp;where k \< 1\
重點來啦，這個 DPH 會不會大到讓持盾的傻逼吃土，我們就要實際試著算看\
\
\

## <font color="#3333ff">追加爆傷爆率對DPS增益的速查圖與公式</font> &nbsp;&nbsp;Tue Oct 30 23:35:44 2012

其實網路上已經有很多方便的計算機可以用，不過我天生比較懶，不喜歡打數據，所以用程式預先跑了幾個圖表快速查找，主要用於估算更換武器飾品時，調整爆傷爆率後大概會對 DPS 有多少影響。\
\
\
先列出個簡單公式，後面會解釋原理\
\
公式 1 ：\
\
若原本的爆傷與爆率乘積接近 1 ，那麼純粹增加爆傷的的追加傷害 ％數相當於(原始爆率 \*追加爆傷)&nbsp;/ 2&nbsp;&nbsp;\
若原本的爆傷與爆率不是一，則上是的 2 改成 1 +原本爆傷\*原本爆率\
\
\
公式 2 ：\
\
若原本的爆傷與爆率乘積接近 1 ，那麼純粹增加爆傷的的追加傷害 ％數相當於(原始爆率 \*追加爆率)&nbsp;/ 2&nbsp;&nbsp;\
若原本的爆傷與爆率不是一，則上式中的 2 改成 1 +原本爆傷\*原本爆率\
\
\
公式 3：\
\
若追加爆傷爆率前你有 40％ 爆率與 250％ 爆傷，那麼對你來說 10％追加爆率&nbsp;＝ 62.5％&nbsp;追加爆傷&nbsp;效果。以此為基準，爆率比 40％ 低則追加爆傷可以升值，反之則貶值。\
\
\
公式 4：\
\
討論純加爆率好還是純加爆傷好，取決於你現在的爆傷爆率。你的 1 追加爆率等於 X 追加爆傷，X 等於你的原始爆傷/原始爆率。 假如你原本有 20％ 爆率&nbsp;&nbsp;200％ 爆傷，那麼你的 1 追加爆率等於 10 追加爆傷。\
\
公式 5：\
\
同時變更爆傷爆率該怎麼辦？ 請查本文提供的圖。以下是一個最典型的快查圖，假設原本預備 30％ 爆率，250％ 爆傷，在相同 DPS 武器下（這裡指的是武器面板 DPS，不是總和 DPS，因為武器 DPS 不計入爆傷）\
\
\
橫軸是追加爆率，縱軸是追加爆傷，顏色代表可以額外增加的傷害比例。比如說我增加 8% 爆率，40％ 爆傷，那麼查圖差不多是淡青色的位置，得到的額外傷害約 0.14～0.29 之間， 算 0.22 好了，那差不多就代表 22％ 額外傷害，換言之你的 DPS 變成原先的 1.22 倍。\
\
圖片的計算原理使用爆傷爆率公式 DPS = 1 + （原爆傷\*原爆率），那麼額外增傷造成的 DPS 被動為 1+(原爆率 +&nbsp;追加爆率)\*（原爆傷+追加爆傷），最後在將這個值除上 1 + （原爆傷\*原爆率）就代表你的相對 DPS 增加為原先的幾倍。圖表已經幫你扣過 1（追加傷害前就有的 DPS），所以圖上查到的數據相當於你的淨增傷比例。\
\
\
其實這個東西不用查圖也能算，把上述式子整理後會得到淨增傷比例是\
\
\
原爆傷\*追加爆率&nbsp;+ 原爆率 \*追加爆傷&nbsp;+&nbsp;&nbsp;追加爆率\*追加爆傷\
\-------------------------------------------------------------------------------\
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;1 + （原爆傷\*原爆率）\
\
\
一般而言換武器通常追加爆率&nbsp;為零，所以可以把上式化簡成:\
\
原爆率 \*追加爆傷&nbsp;&nbsp;/ (1 +原爆傷\*原爆率)\
\
正常有點裝的人 原爆傷\*原爆率 大概都有接近 1（假設是 40％ 爆率 250％ 爆傷），所以換武器得到追加爆傷後大概得到的額外傷害會是&nbsp;(原爆率 \*追加爆傷)&nbsp;/ 2，也就是說，如果我有 40％ 爆率，透過換武器得到 50％ 追加爆傷可以讓我得到約 40％\*50％/2 = 10% 的傷害\
\
假如純粹追加爆率，則式子簡化成 ：原爆傷 \*&nbsp;追加爆率&nbsp;/ (1 +原爆傷\*原爆率)\
\
如果我有 250％ 爆擊傷害，那麼追加 10％ 爆率可以讓我獲得 250％\*10％ /2&nbsp;&nbsp;約 12.5％ 額外傷害害。我們很容易發現對40％ 爆率 250％ 爆傷來說， 10％追加爆率&nbsp;的效果相當於 62.5％&nbsp;追加爆傷，對於這個原爆傷\*原爆率差不多為 1 的人這個換算比例是差不多的，如果原本爆率較高，那麼追加爆傷會值錢一點，如果原本爆傷高，那麼追加爆率會值錢一點。\
\
最後討論公式 4 的算法，\
\
