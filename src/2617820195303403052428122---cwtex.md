<br />這種奇妙的 bug 主要在於 cwTeX 是類似超級外掛一樣的存在，將中文字碼轉譯成 LaTeX 可以處理的字碼並且嵌入版面，使最終得到的向量描述頁面缺少最原始的中文編碼資訊，所以直接複製會得到亂碼，因為打開的 pdf 檔中根本沒有 cwTeX&nbsp; 轉譯的規則。當初覺得這個缺點很討厭，甚至一度改用 CJK package 來避開這個缺點（在網路上找到把 cwTeX 的字型轉成 CJK 套件可以使用的方式，沒記錯的話應該是[蔡炎龍的教學](https://docs.google.com/file/d/0B1C5aL1-2qlMaUt0S3ZJdHRSZ3FGOEpsR1plNWlkQQ/edit)），現在想想這搞不好才是 cwTeX 最強大的應用： <font color="#ff0000">你可以用它編出無法被簡單複製的 LaTeX 版面 PDF 文件耶！ </font><font color="#666666">對於很討厭 copy&paste &nbsp;的人來說這個根本是超強的防盜功能（比如說編寫講義的老師很討厭學生寫作業的時候直接 copy 引用大量講義內容，覺得學生這樣很沒誠意）</font><span style="color: rgb(102, 102, 102)">，不需要額外轉檔與程式就可以輕易製作此類文件，實在是居家旅遊必備良品哪！</span>\
\
\
<font color="#666666">我並不是在酸 cwTeX 系統有多差，相反地，我使用&nbsp;</font>cwTeX &nbsp;編輯過的文件量相當大（超過生涯總量的三分之一）。<font color="#666666">在 2009 年以前 cwTeX 幾乎打遍天下無敵手，安裝難度遠低於其他中文解決方案（主要原因在於作者吳聰敏、吳聰慧老師編寫的[中文使用說明手冊](http://homepage.ntu.edu.tw/~ntut019/cwtex/cxbook3.pdf)過於強大，強大只要你接受他對於中文字體的排版邏輯，你就可以照本宣料用 cwTeX 編出一本完整的書籍），即便你對於 LaTeX 一無所知，還是可以透過它的使用手冊學習 TeX 排版系統的核心概念，等你熟悉 cwTeX 的操作之後（標題、章節名都需要重定義，還用了不少&nbsp;</font>\\renewcommand&nbsp;<font color="#666666" style="font-size: 13px; line-height: 1.5;">）</font><span style="color: rgb(102, 102, 102)">，要跳槽到其他系統或者使用更多 package 都不成問題。</span>\
\
<font color="#666666">整體上我使用中文 LaTeX 系統的歷史大概是這樣子：</font>\
\
<font color="#666666" style="font-size: 13px; line-height: 1.5;">cwTeX &nbsp;(2007-2011) -> &nbsp; &nbsp;CJK package</font>&nbsp; (2010-2011) -> XeLaTeX (2011 - now)&nbsp;\
\
\
有一段時期我 cwTeX 跟 CJK package 混用，大約是 MikTeX 2.8版之後， XeLaTeX 開始流行的時候才固定使用 XeLaTeX（畢竟 MikTeX 一裝好就可以直接用，非常方便）。每個時期都有編過 50 頁 up 的文件，<font color="#3333ff">基本上只要整個環境（程式，字體安裝與相關設定等等）建立好，編寫過程都差不多，只不過 cwTeX 需要事先呼叫 cwTeX 來預編譯 TeX 文檔罷了。</font> 只要使用同樣的字型，同樣排版指令製造出來的中文文件看起來簡直完全相同。\
