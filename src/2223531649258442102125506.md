打前陣子弄了大跳水的燈泡牌 X2 (massdrop 那批) 之後, 囿於耳機特性(中低頻力度足而不溢, 換線上擴後型體感整個浮現出來,)開始聽一些古典大編制(以前用 w1000x 時頂多聽聽弦樂四重奏), 聽著聽著總覺得調音上欠缺了一點味道, 乾脆入了管擴的坑, 調著調著整個系統開始朝我想要的方向走(一邊寫 code , 一邊輕鬆聽上一兩小時的工作用系統), 估計直上旗艦之前可以頂一陣子\
\
整個系統主要走數位流, PC foobar ASIO 輸出 -> XMOS U8 同軸 -> 樂之邦 MD30 dac ->雜牌 6N 無氧銅 1m ->&nbsp;Yu-Studio 的四管耳擴--> Oyaide HPC-62, 2.5m -> philips X2

![Picture](/uploads/8/4/4/0/8440048/1963922_orig.jpg){@.none}

系統照. 一根鋁擠型可以串四五支, 還打算進 DT990 600 ohm 跟 HD600 or 650 將各家次旗艦玩過一輪\
\
數位的部分其實跟usb直插 dac區別不大, 有興趣的可以參考我以前的文章, 非同步帶 local clock 的MD30 是我覺得性價比很高的玩具, 不過基於好奇弄了兩三個廉價的 DDC 發現對岸偉良的 XMOS-U8 (0.1ppm TCXO) 量起來雜訊跟 jitter (peak-to-peak 應該不到 500 ps, 個人認為已經超過我示波器 timebase 的精度, 應該要改用相位噪音來量, 不過用來比較低價位 DDC 規格相對優劣還行具)都超小就試著用了. 過陣子打算弄台 titan&nbsp;Athena SE 讓這套昇到定位, 選對岸產品主要還是顧慮到未來拆機改機研究時比較不會心痛 . 整體打造成本（管子只算目前試完的最佳組合）大概 DAC：擴：耳機=1:1:1, 同價位選其他的組合感覺不太容易搭出同質地的聲音(X2 絕對是跳水界的 C/P 霸者)，歡迎同好來家訪踢館 XD\

先回到 X2 來討論,很多文章對這隻的評價不外乎是原廠線很糟, 直推很不賴之類的, 剛入手時我認為以原廠線而言配直推(比如說 ipod classic, 個人的經驗)其實還算OK, 但是器樂分離的層次感,空間定位以及耐聽的調性完全顯現不出來, 即便換線也沒用, 以萬元左右的價格來考量不會是很好的選擇. 不過一旦替它找到堪用的前端與合適的擴之後, 換線的優勢馬上會反映出來(也許是沒 run 夠,不過我覺得調性很難再變化, 以 500hr+ 左右的狀態來說原廠線給我的感覺就是人聲太刺, 低頻的質感不夠好, 不耐久聽), 找到管擴來配之後很快就調出自己想要的聽感:被眾多樂器包圍, 聽感溫潤,帶韻味卻不失層次, 定位清晰而不會太刺激; 不過調到最後會變成很不適合聆聽 ACG ,流行樂等等 (不過擁有其他耳機可以完美解決這個問題)\
\

一半是四管擴二手收來就附的舊管, 然後就快速增殖了

\
目前還在享受換管的樂趣, 用 Simens/TFK 退燒之前大概還可以玩上好一陣子 (很努力想找便宜一點的管子調出想要的聽感, 不過一分錢一分貨, ECC88 這種常見的管子好的組合大概都反映在價錢上, 反正淘汰下來的次級品都打算用來當作 DIY 練手的犧牲品), 以目前的進度來說每天大概可以試 2\~3 種組合. 現階段配管的心得不多,有試了一批 ECC84 來替代不過結論是非常不合適, 除了修改電路(也許偏壓工作點, 增益也不太夠)以外很難在這個四管擴作出韻味\
\
以搭配 X2 來說我覺得以下的搭配還湊合\
\
1\. 整流:GEC 6x4, 要配 X2 出的紮實聲底這個選擇不多, 為了節省時間幾乎都預設這隻去配了\
2\. 訊號管: BRIMAR 6DJ8, 我覺得用一些比較高價的古典管效果都不錯\
3\. 功率管:復刻金獅 6922, 一直很想用便宜的現代管來配這一對, 也準備了幾對號角男孩當備管\
​\
​用來試音的曲目跟以前差不多, 請參考&nbsp;​[將量測級設備作為 DAC 使用](/25343373272820432026207362212030070dac29992.html)&nbsp;, 相性高的曲子以大編制為主，假人頭錄音也是一絕. 女聲的部份完全不行, 只要背景樂稍微有點節奏很容易就分心被吸引過去, 唯一還過得去的人聲大概是像這樣子的類型：\
\
