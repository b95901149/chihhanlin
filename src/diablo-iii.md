這裡收錄的主要是我從 1.05 版回鍋到 1.06 quit 之間撰寫的技術文件，核心目標就是找出以相對廉價的裝備來取得高成就感（高 MP 、紅門特化）的技能配置（build），最後得到的結論便是持盾並以高爆率先祖鎚為主要輸出的劍盾先祖蠻；這個技能配置的概念我不敢說是我獨創的（類似的作法大概在 1.04 PTR 時我就有在凱恩之角看過，不過那是以相當高階的野蠻人裝備來實現），但是深入研究、量化這個技能組的極限，並將它用在當時中低階裝備的野蠻人去打高 MP 精英與紅門的作法上我可以算是開創者。當時我已經認為回怒機制觸發近無限先祖鎚的高傷害配合重腰與被動的吸血屬性肯定會成為未來的主流配置之一，如果能有效配合無盡之怒（超賽），那麼野蠻人絕對會是最 imba 的職業（無視控場，實際輸出 DPS 比帳面多上 5\~10 倍）。1.05 之後先祖鎚果然成為野蠻人打高 MP 的專屬綁定技能， 能維持先祖鎚連發的高爆率滿怒的配置變成追求高輸出的最佳方法。\
\
\
\
玩了一陣子的 1.05 我發現對於我的配置而言，整個遊戲的難關幾乎只剩下 MP9 以上單挑紅門 BOSS ，而這個瓶頸完全取決於機體的 DPS （如何在 BOSS 狂暴的時間內解決掉它），對於非職業又不想花實體貨幣的玩家來說要取得這種等級的裝備需要相當多的時間，於是我便開始往 Hardcore 的方向探索，在大約 100 hr+ 的遊戲時間取得了相當多的樂趣（由普通至地獄 MP10 通關， 幾乎不怎麼農裝，不跳關 solo&nbsp;擊敗煉獄 MP0 Diablo&nbsp;）。\
\
\
\
為了測試技能組的極限，也想出很多 softcore 的遊戲方式，比如說空裝打 BOSS，僅買商店藍裝來推煉獄進度，甚至是 &nbsp;Act1. lv0 speed run 等等特別的玩法，直到找不出新玩意的時候就順其自然 quit 了（累積 Barbarian 時數約 680+ hr）。受益於 Diablo III 的拍賣場功能，不管你什麼時候 quit，只要你對技能配置有概念，回來的時候總是能夠用很快的速度取得當時版本的中階裝備，想刷寶的時候開來刷，或者嘗試另類的玩法，Diablo III 對我來說是個很好打發零碎時間的遊戲，而我不需要持續專注在它身上。<br /><br /><br /><br /><br /><br />

## <font color="#3333ff">如何用 PS3 搖桿操控野蠻人玩 D3 &nbsp; &nbsp;</font>

主要是利用 Xpadder 4.3a [http://www.majorgeeks.com/Xpadder\_d5282.html](http://www.majorgeeks.com/Xpadder_d5282.html)\
\
這個軟體作對應，假如要用 PS3 搖桿的話推薦 &nbsp;MotioninJoy 當 driver\
<a href="http://www.motioninjoy.com/" style="font-size: 13px; line-height: 1.5;">http://www.motioninjoy.com/ </a>&nbsp;(選用 Xbox 360 controller emulator 模式)\
\
\
基本上設定中最關鍵的在於移動模式怎樣才能順暢，個人覺得最好的設定方式是採用將類比搖桿 （control setting 中的 stick） 設定到滑鼠的上下左右，同時把移動確認鍵也同步設到四顆方位按鈕上，mouse setting 採用 spring&nbsp;mode (游標位置正比於類比搖桿深度，換句話說鬆開香菇頭游標會回到畫面正中央)&nbsp;這樣移動就不會有問題。\
\
\
玩旋風蠻的甚至可以利用第二組類比搖桿來作成旋風斬專用移動模式 （再把技能鍵重複設定疊到搖桿上（在 advance 選項中改，理論上要疊幾顆對應的鍵盤鍵都沒問題），至於剩下的 △○□╳ L1 L2 R1 R2 放左右鍵與招式對應鍵、藥水與 Tab&nbsp;切地圖，站定鍵，不夠用就把香菇頭本身按鍵（L3 R3）拿來放長 CD 的招式；至於實際使用我覺得大概可以作到鍵鼠 70％ 的流暢度，缺點也很明顯，撿東西麻煩，指定位移技會慢半拍且不夠精準（通常也不太能用 spring mode），而且還有違法巨集的風險（畢竟也不是官方認可的操作介面）\
\
\
\
不過優點就是玩起來很舒服，特別是裝備稍微高於 MP 要求時（比如說速刷經驗的時候）。聽說 &nbsp;BZ 有把 D3 移植到家用主機的計畫，真有這麼一天玩起來大概就是這樣的感覺。我認為以搖桿作為介面主要問題的問題有三個：\
\
\
1.) &nbsp;指定位移技的有效施放 （ex. 躍擊，狂暴衝鋒等等）\
2.) &nbsp;非移動遠程技能的一鍵施放 (ex. 擲刃斬)\
3.) &nbsp;拾取物品的便利性\
\
\
如果可以很漂亮地解決這些問題，用搖桿玩起來的爽度不輸鍵鼠\
