仿侏儒の言葉短喻體\
\
\
\
\
\
1\. 在清冷的午夜漫步有助於思考。\
\
\
\
\
2\. 優柔寡斷的特效藥是信仰；\
\
&nbsp; &nbsp;你心底的燕子是一種信仰，閉上眼最常想起的人也是信仰，\
\
&nbsp; &nbsp;沒有信仰的人不足以稱為真正的無神論者 ----\
\
&nbsp; &nbsp;無法明白這樣抽象概念的重要性就難以堅實地捍衛你的心，以及目標。\
\
\
\
\
3\. 我以為我有信仰。\
\
\
\
\
\
4\. 我時常假裝虔誠信徒口中的上帝就存在我心底；\
\
&nbsp; &nbsp;暗夜的禱告只有心底的燕子聽的到，那是真正的我，姑且假設那是\
\
&nbsp; &nbsp;全智全善的一個無窮集。\
\
\
\
\
\
\
5\. 異教徒如同非歐幾何，宗教式的自我陶醉連無神論者也有，幸好我也有。\
\
\
\
\
6\. 你不是我，所以我不必也不需要告知你我心底的憂傷，\
\
&nbsp; &nbsp;所以獅子座總是讓人以為他永遠快樂。\
\
\
\
\
\
7\. 或許真的快樂也不一定？\
\
\
\
\
\
8\. 悲傷只有心底的燕子能分享，那天你成燕子銜走了這份鬱便成了知己。\
\
\
\
\
\
9\. 算算機率，藏住悲傷的可能性大些，所以釋懷。\
\
\
\
\
\
10\. 我寧願人生像是非題而無太多選項，所以可以悠然走出森林。\
\
\
\
\
\
11\. 仔細想想，複選題不也只是無排列的是非題麼？\
\
\
\
\
\
12\. ABCD law 已經表明了如何處世：\
\
&nbsp; &nbsp; 近軸近似從不完美中湊合出了描述現實的捷徑；\
\
&nbsp; &nbsp; 把複雜的東西拆成簡單的元素才能分析：\
\
&nbsp; &nbsp; 你以為人生只是不可交換的矩陣嗎？\
\
&nbsp; &nbsp; 它其實是 bilinear transform ！\
\
\
\
\
\
\
13\. 更多時候仍得回到麻煩的積分式，你以為事情永遠往想像的\
\
&nbsp; &nbsp; 理想發展嗎？\
\
\
\
\
\
14\. 完美主義者特別容易陷入嚴重的聚焦或發散，這根本不是近軸，\
\
&nbsp; &nbsp; 當然你心知最後只會剩下發散而已。\
\
\
\
\
\
15\. 無憂無慮只是理想的產物，如何藏慮解憂才是工程師的志業與專長。\
\
\
\
\
16\. 兼具搞科研的天馬行空與工程師的妙手生花才是王道。\
\
\
\
\
\
17\. 燕子叫我醒著，我便眐著眼，叫我眠，我闔雙目；\
\
&nbsp; &nbsp; 我抗衡不了機率，卻能自在調整心底的權重，結果仍可接受。\
\
\
\
\
\
18\. 拿起它，也能放下它；\
\
&nbsp; &nbsp; 不能隨時拋下又何必拿起？\
\
\
\
\
\
\
19\. 真正需要的潛意識拋不開，不必拿就在心底，\
\
&nbsp; &nbsp; 所以分得清可拿可拋為何者才是重點。\
\
\
\
\
\
\
20\. 我太自滿，我以為我有信仰，矛盾。\
\
\
\
\
\
21\. 心底的燕子啊我在和說話，我祈求哀傷的昇華。\
\
\
\
\
\
22\. 書是我底燕子，深邃的湖是我底燕子，我仍然在追尋更多燕子，真正的燕子。\
\
\
\
\
\
23\. 芥川的侏儒與我的獅子。<br /><br /><br /><br /><br />
