## <font color="#24678d">121T 消防役專訓攻略</font>

雖然我知道謝區可能正在後面看，不過身為一個專業鄉民，還是要秉持的公正公平正義的原則將自己看到的體會到的東西記錄下來（下單位再一次寫完容易漏掉細節，還是想到就寫下來比較保險），請完整看完再決定要衝安全島還是口頭嘉勉 XD\
\
首周心得：\
\
1\. 撥交日：到了竹山就會依照身高來重新劃分隊形，編學號，選學員長，順便練習一些基本的口令動作。<font color="#8d2424">基本上從成功嶺剛出來的草履蟲群抓幾個跑安全島來殺雞儆猴一下馬上就會發現你那原本桀驁不馴的同梯很快就進化成復活島石像，</font>令人不禁慨嘆，當年在大學裡頭當助教帶課要是也能用這招，至少可以省下 50% 以上的集合時間。這一梯的區隊長是謝區（首周值星的樣子）、鄧區還有魏區，<font color="#8d2424">基本上各種規定都已經事先講得很清楚，乖乖照做就不用擔心記基數，不懂的事一定要報備（衣著問題之類的，反正只要記得跟鄰兵不一樣的地方都要事先找幹部報備）</font>；整隊站定的時候不要摳摳摸摸、嘻笑打鬧、眼神鎮定直視前方就不會有事，第一天適應期彈性更大，聽錯幾次口令也不會真的處罰，請各位儘早熟悉。\
\
2\. 違禁品：舉凡非手機類的電子產品（包含 mp3，充電器都算違禁品，<font color="#8d2424">行動電源、手機電池、手機用耳機不算</font>），菸酒、書籍、喉糖等。第一週違禁品會統一收管，第二周以後除特殊事由（離島役男放假回不去之類的）外一律不准帶，能不帶千萬不要帶，上次我不小心帶了喉糖跟 mp3，<font color="#8d2424">就發現我</font><font color="#8d2424">犧牲了禮拜五的午休時間來領違禁品，很不方便。</font>違禁品發還後記得直接入行李，不然會吃基數（區隊長有重複講，就是有人沒在聽，阿就真的吃基數）。\
\
\
<font color="#8d2424">喉糖是最容易誤帶的物品，這個之所以會被列管主要是因為以前學長在上課集體啪姿啪姿的嗑，一顆接一顆，然後教官就生氣了，</font>於是往後的區隊長就決定直接禁喉糖免得惹教官不高興。假如你進竹山前有染上成功嶺感冒病毒，<font color="#8d2424">喉嚨真的很不舒服，還是可以帶藥用喉糖進去（就沒病吃了可能會出事的那種，有藥用成份的那種）</font>，可以視為個人藥品。\
\
\
手機可以帶，會統一由寢室長收集並負責發放工作（通常一個禮拜有兩天晚上開放打電話），真的沒手機的要跟隊長申請使用公用電話機。\
\
\
3\. 長官好：逢人問好是規定的禮節，有巴結長官，凸顯自己有紀律的作用。<font color="#8d2424">基本上遇到三個區隊長一定要記得問『區隊長好』</font><font color="#8d2424" style="font-size: 13px; line-height: 1.5;">，這個通常第二天就會把臉記起來，所以不容易混淆。區隊長心情好（我以前帶助教課也喜歡學生來打招呼，一整個就是爽，沒來招呼的都會特別注意一下），我們也會很好。</font>遇到授課教官通常要問『教官好』，這個也很好認，穿黑色基調（或者比較帥氣的那種衣服），有 EMT 相關圖案的就是。至於遇到其他同在訓練中心受訓的學員（特考班、受訓的長官、警專警大之類的）與消防役學長要說『學長好』，看起來比較菜的就當成學長，<font color="#8d2424">有些一看漢草不錯，霸氣外漏（看起來可以一拳把你打飛的那種，消防人員不愧為全國肉體最精實的公務員）的應該就是長官了，除非他們三三兩兩聚在一起專心聊天，不然經過得時候最好問個好。</font>有一種穿水藍色衣服的警專 NPC 反應比較奇怪，通常你跟他講學長好他不會有反應（可能菜鳥程度跟我們差不多，也是逢人就要問好的那一種，所以被問好會不好意思），路過的時候點個頭就好。\
\
<font color="#8d2424">另外還有一種特殊 NPC，叫做訓練中心主任（boss 級，平常笑笑的像肯得基爺爺的那一位），會在課堂、早上打掃的時候遇到，這個時候請提高注意力，集體問安，這是提高本梯役男好感度的最快方式。</font>\
\
<font color="#8d2424">以上都是廢話，假如你不會應對，最好的方式就是不要落單，儘量跟著其他鄰兵走，用眼角餘光觀察一下，人家喊什麼就跟著喊，保證不會出事。</font>\
\
\
4\. 務必加帶的日用品：<font color="#8d2424">衣架請帶個一打，洗衣粉請帶個一罐來與室友分享，水杯請多帶一個。</font>以前心得文寫說公發只給三隻衣架，還真的只有三隻衣架，正常人絕對用起來很不爽（毛巾、幾件短袖內衣、內褲、襪子，第一天脫下來的制服，站哨要穿的制褲，隔天跑完步要換得的新內衣得輪流掛），假如你有一打，把一週下來所有汗水打溼內衣吊起來晾乾，周末帶回家洗都沒問題（不過不建議，有點噁）。記得帶洗衣粉的人很多（公發的常常隔天就不知所蹤），但是記得帶衣架的非常之少，<font color="#8d2424">最好帶個兩三打進去一人發一隻，這樣做的話就算你想連署篡位當學員長我想都沒有問題。</font>\
\
水杯的話會統一放在教室（通常是成功嶺公發的那個），寢室內會先暫時分幾個公發的給學員一起用（一寢 12 人配 3 個杯子）。通常寢室只有早、中、晚會回去一次，<font color="#8d2424">早上那次最重要，因為剛跑完步只留五分鐘的時間給你換衣服，這個時候如果沒有預先打滿一杯水放在寢室預備在這個時候喝，差不多要 20\~30 min 後才能在餐廳裡排隊盛甜湯才能補充水分，</font>假如你跟我一樣很會流汗的話，最好趁這五分鐘補充約 200 cc 左右的水分比較好。\
\
5\. 內務評分：<font color="#8d2424">內務櫃可以隨便塞，不會看內容，只要記得蓋起來就好；</font>棉被（折豆腐）跟床單（拉平）都是重點，前者的標準比成功嶺高一些，不過<font color="#8d2424">個人認為竹山這裡的棉被比較硬，好折很多</font>，不才在下我成功嶺很少因為內務加分，來這裡就因為棉被加過兩次。下午偶而也會評，自從某天棉被早上被加分，下午扣回去之後我就決定午休躺床上，折好的棉被供在旁邊就好。至於床底下的拖鞋、運動鞋與臉盆擺放就要請睡下舖的幫忙留意或者每次出寢室的時候檢查一下，有時後會被失腳踢歪。\
\
雖然棉被我覺得好處理，不過每個人感覺都不太一樣，比如說某天早上我是全寢最後一個醒來（比 5:40 正常起床時間早個五分鐘左右），發現大家居然都在努力折棉被，還真的有不少因為被扣過兩次甚至三次以上分數的人，開始專注在這項內務上。\
\
6\. 基數與體能懲罰：<font color="#8d2424">犯錯就直接記基數，報學號也要照律定的方式來，不然會 double。基本上用餐保持安靜，不要隨便笑、扭動、亂放炮，該帶的東西要帶，原則上不用擔心被罰，</font>比如我第一週沒被記到半個基數。首周基數通常 30 起跳，放假前一兩天晚間體適能開始以前就會叫出來清基數，通常是伏地挺身，往後兩週會不會改版我不曉得。集合時過慢入列也會有少許處罰，比如蛙跳之類的。\
\
<font color="#8d2424">如果是室外集合，處罰可能改成直接跑分隔島，</font>個人覺得最幹的是集體跑分隔島（守規矩的人會被帶賽到的機會），一次大概是有人沒蹲好，一次是唱歌時集體搶拍，最經典的地方在於最後五個要在跑一次，科科，我就兩次全中了（作為一個邁入 26 歲高齡、在實驗室裡坐了六、七年的宅宅，基本上跑不贏年輕小伙子，跑在前頭的人還有力氣罵放炮的，我只能在後面撿大隊人馬掉的寶，比如垃圾袋、雨衣、面紙之類的），幸好隊長很仁慈，真的沒力氣跑稍微用走的也 OK。\
\
<font color="#8d2424">至於幹了會被罰基數的事而沒有被罰偶而會有，代表你人品好，</font>比如某天早上整個上午我忘了帶狗牌（名牌），居然沒有半個人發現（包括我自己），恁爸還是站排面班的，一直到吃完午餐回到寢室打開內務櫃才驚覺：ㄟ～，怎麼有張熟悉的名牌放在衣服上。原則上只要態度顧好，基本上不太容易招惹區隊長罰基數的目光。通常鄰員看到你東西沒拿都會幫忙提醒，真的出鎚就看人品了，記得保持鎮定，維持良好態度。\
\
<font color="#8d2424">通知單上叫你帶的東西請記得，比如輕便雨衣、一吋半身照（EMT 發照用），</font>不然每樣都是兩個基數。\
\
隨身攜帶物品：<font color="#8d2424">雨衣、藍色垃圾袋（晨掃用）、藥品</font><font color="#8d2424">、面紙（optional）、名牌、口罩。最好隨時塞在口袋裡。</font>晚上嫌口袋太滿不好翻身就脫褲子睡。基本上東西放內務櫃就有一定的機會忘了拿，除非你寫了一張 check list 貼內務櫃門隨時參照。\
\
7\. 隊歌：只要你在成功嶺會唱亮島之歌，就會唱慾火鳳凰，但是也不能唱的太熟，不然最後一句的替代役很容易唱成 X 中隊。不<font color="#8d2424">懂的也沒關係，某天下午的區隊長課會連續放個二十次洗你的腦讓你學，只要注意最後一句的浴火重生奮戰到底不要忘詞（但凡軍歌，新手剛開始學的時候最後一句一定含糊帶過，成功嶺唱了十幾首都是這樣，我覺得很神奇的經驗定律），切到主旋律的時候要空一拍（朝字左腳，右左右一拍半後左腳接『不怕...』</font>\
\
\
8\. 標準蹲姿：<font color="#8d2424">我認為便秘的人都應該學學標準蹲姿，</font>這幾天跑廁所的頻率讓我覺得有點誇張，沒事就想撇條，甚至懷疑自己是不是有大腸躁鬱症 XD。 標準蹲姿的另外一個作用是鍛鍊小腿的肌肉，蹲到第四天我突然發現腳好像沒有那麼酸，我想蹲到結訓應該跑去打壘球蹲捕都不會有問題。\
\
9\. 學員長：第一天會選出負責集合、掌控秩序、清點人數、帶隊跑步的正副學員長。<font color="#8d2424">當學員長有加分，不過如果記憶力不夠好，聲音不夠宏亮或者霸氣不足，震懾不了學員，很容易跑安全島或者做基數。</font>我覺得第一週執行的學員長喊命令的準確度（咬字很清楚，聲音夠響亮，這個我覺得很重要，千萬不要亂選）已經贏過不少成功嶺受過區訓的新手隊長了，不過一週下來還是做了五六次基數或者安全島。\
\
\
10\. 晨操：<font color="#8d2424">用相當慢的速度（連我可以跟的上，真的不快）</font><font color="#8d2424">一邊報數、報口號繞訓練中心約 3000m （耗時二十分鐘以上），聽說跑不好的時候（喊得不夠大聲，夠大聲會聽到整齊的回音）會加圈，</font>不過目前還沒遇上。真的跟不上可以退出去繞安全島的樣子。我自己跑到一半左右就跟不上喊口號了，到後面甚至有點喘不過氣的感覺（對不起各位同袍，請你們喊大聲點），偶而會想脫隊去跑安全島，最後還是咬牙跑完，畢竟<font color="#8d2424">每天只有這個時候可以練心肺。</font>至於腿部肌肉的強度透過晚上的體適能與白天整隊的標準蹲姿比較容易練，甚至下課有空閒的時候都可以自己撥時間練，唯獨心肺一定要拉長時間才練得起來。\
\
以下是個人練跑的心得，假如你三千隨便跑都 15 min 內請不要笑我。\
\
我放假的時候（其實從成功嶺到現在也只有四天而已，可以練的時間太少）早晚會各跑個 4\~5 km 左右，從暖身，伏地挺身，開閤跳、抱膝、3000m 慢跑（距離逐次拉長）、衝刺加快走、再接一兩輪開閤跳把腿部肌肉操到稍微緊繃，抱膝（真的會痛到飆淚）然後再收操，有餘力再接伏地挺身之類。回家洗澡以後就按摩肌肉，基本上肌肉酸痛的程度可以早晚各來一輪。<font color="#8d2424">之所以我覺得心肺太差是因為速度不快，心率就飆到 170\~190 （還有點臉麻，帶耳機會聽到很明顯規律的咚滋咚滋聲</font><font color="#8d2424">），我練跑的時候就儘量把這段時間拉長（一開始十分鐘，然後越來越長，越來越長），聽到的咚茲變快成接近咚茲咚就減速，他媽的對一個在大學宅了七年、腿長比別人短十啪的肥仔來說這麼做真的很痛苦，但是超級有效，</font>從成功嶺前的 27+ min 跑到現在 21\~22 min ，這就跟玩 D3 練巔峰等級一樣，練等時枯燥無味，短期看不出效果，但是長久下來體力就提昇了。\
\
\
我跑步大腿都不會酸，很奇怪，大概是常常騎單車的緣故（入伍前固定每天騎 50\~100 km，車重都 20kg+），假如你常常跑到大腿比小腿疲累，應該可以用騎單車來練（主要操到大腿跟上半身的肌肉），到壽山忠烈祠那邊爬坡或者澄清湖狂繞圈，抗曬能力也會大幅提高。\
\
無論如何，在專訓的三個禮拜內肉腳如我還是沒辦法練到令人滿意的程度，三千預測的時候看到那種跑進十二分的強者，當下就體悟到當年考完大學的時候，很多人看我應該也有差不多的心態，就是那種即便爆肝也很難在一兩年內搆到邊的絕望感。\
\
11\. 晚間體適能： 每週一次的基數，開閤跳、伏地挺身、仰臥起坐、類似海狗趴的動作（虎什麼的我沒聽清楚）、龍騰虎躍之類鍛鍊肌力的動作。做不好就追加一組，第一週適應期，基數低，也沒有全套都做，怕影響到 EMT 考周的關係所以強度有點低。我個人因為養出鮪魚肚的關係所以仰臥起坐有點跟不上，跟不上就補做，我仰臥起坐最後一下硬撐到四十五度撐了好幾秒就是拉不上去（被肚子卡住的感覺真的很奇妙，瘦子不會體驗到的），最後不得已用手拉也沒被加罰，所以說我覺得這梯區隊長都挺善良的。\
\
消防役強化體能有正當理由（壓 CPR ，跑救護的需要體力、耐力），想跟外勤跑救護（雖然我現在體力墊底，不過真的很想走這塊）就儘量練吧。\
\
\
12\. 周遭環境與設備：竹山訓練中心不愧是花了幾個十億蓋的訓練場（雖然大部分的錢都投在訓練設備上），給訓練學員住的宿舍基本上還不錯，廁所很大間，空氣好、有山有水氣氛佳。<font color="#8d2424">特別是傍晚從餐廳出來看到的那一片晚霞，有良好的心裡慰藉效果</font>（特別是颱風要來的前一晚，非常想拿相機把橫向全景拍下來當網頁元素用）。教室設備也很棒，<font color="#8d2424">唯一令人不滿的地方在於沒有大澡堂，對，就是它，吞吐量超大超有效率的大澡堂。</font>只有隔間浴室，前幾天洗下來有不少白目佔坑佔太久，讓後頭的人沒啥時間洗（大概沖一下，肥皂泡來不及沖掉就要準備出來）。不過禮拜五的時候稍微有點好轉，也許大家都體驗過沒時間洗的痛苦（每個區隊優先度輪流排，三天一輪，爽一天苦兩天），所以有自覺地提高洗的速度。\

再來就是脫水機，還真的有很多人不太會用，重量沒分配原則上轉不起來，其實遇到重量嚴重不均勻的時候丟條毛巾下去喬平衡就解決了，簡單又快速。\

13\. EMT 課程與郭教官：初級緊急救護課程裡面有個扮演被包紮病人的好像就是郭教官，如果不是，也應該是他雙胞胎弟弟，長得非常像。簡言之，<font color="#8d2424">郭桑是個講課極富感染力的高階鄉民，講得我如果再年輕個五六歲也許就一頭熱地跑去考消防特考準備轉行之類，</font>當年我也是被嘴砲等級差不多的狠角色所影響，跑去搞基礎實驗物理教育的說。這裡的 EMT-1 很注重術科的操作，畢竟以後跑外勤絕對常用，許多流程都有固定的 SOP 可以學（SOP 就是讓笨蛋也能變成專家的偉大發明），不過教官教的會跟課本不太一樣（簡單說課本講的太落伍） ，實際操作的時候真的不熟都有鄰兵提醒，不然示範時屁顛屁顛自願到台前讓郭桑敲頭加基數保證你馬上記起來。\
\
以 AED+CPR 流程為例，七組人馬（主副手兩人算一組）可以跟安妮玩上六個小時，統計下來至少可以練六次以上，看別人操作三十次以上，差不多練到第三次以上就可以在旁邊挑正在操作組別的錯誤，練到第五次左右主手<font color="#8d2424">膝蓋應該會有點痛（當初應該從口袋掏兩包面指出來墊）</font>，到第六次的時候差不多沒人想碰安妮了，只要找到隊友隨時可以上去練習壓 CPR。至於學科筆試就靠晚自習讀，多看幾遍不知不覺就會記下來了。\
\
<font color="#8d2424">跟成功嶺的垃圾課程比，消防專訓的 EMT-1 真的比較有意義，就算以後不走救護，還是得到基本常識足以讓你應付緊急狀況，有機會就到身邊的人，光就這點也許就值回票價。</font>\

另外郭教官不喝茶，所以早上一二節想睡的就給他搶過來喝沒關係（現在的年輕人喝茶的越來越少，我第一次舉手就搶到了）。\

14\. 繩結：平結算送分，加半扣搞不好還比打主結久。撐人結與三重繫船打法相同，後者為前者雙索版；蝴蝶結會打也差不多十秒可以打好。拴馬跟雙布魯斯克很像，難點應該在於到時候考試要綁在腿上（也就是垂直的柱狀物上），這兩個結的話最好各角度都練一下，比如說拿條童軍繩，走在路上看到電線桿就給他綁一下之類的。接索結與二重繫船結大概要多打幾次才比較熟，纏身結還沒教所以我就不熟了。\
\
<font color="#8d2424">我練的方法基本上就是在區隊長教過一次以後，利用下課時間把學過的結依序打過一遍，不懂馬上問鄰員，差不多五六輪以後就會手指就會背下來，</font>接下來就可以練速度，練的時候補半結，開發高速特化結法之類的。我覺得繩結有可能是四個學科裡面最容易滿分的項目，根據賣油翁原理，唯一字『熟』爾。真的忘了怎麼打，放假回家看 YouTube 學也可以。\
\
15\. 用餐：七菜（包含水果），湯品一甜一鹹，午晚餐有冰綠茶供應，含肉率從成功嶺的 20-25% 提高到 40-45%，熱甜湯通常會搭送幾箱冰塊一起用，偶而會有魚肉可用（我超愛魚頭的說）。用餐禮儀中心思想就在一個『靜』字，最高標準就是用餐毫無聲音（後來想想吃起來的樣子超像日本武士），可以輕鬆聽清楚隔壁電視新聞播報聲的境界。\
\
16\. 收放假：不用回報，收假當天不給請假，就是要請也要回來再說。放假是補日常用品的好機會，不要錯過。\

17\. 簡單感想：大抵上消防工作算是一種志業，在鬼島上尤如此，沒有一股衝動或者同伴（一起衝的人）的人很難一直走下去，所以我很敬佩像郭教官這種口嫌體正直的人（哪天他淡出消防圈再砍掉這句），就跟我以前屁顛屁顛跑去當助教的心情很樣，想對社會做點什麼，有機會就順勢給他做下去了，就算只有影響到一小撮人也很開心。<font color="#8d2424">消防役雖然在替代役中算是有點精實的單位，但是跟常備役相比操的有目的、有價值（我有個海陸的同窗整天在左營不曉得幹麼，大概就是天天跑步天天健康，放假糾團 LOL 見之類的）</font>。假如你跟我一樣，覺得過去的人生浪費太多國家納稅人的錢，想要透過服役的機會稍微回饋一下社會的話，消防役應該是個不錯的選擇。

EMT 考試：第二週的前半段還是屬於 EMT 課程的範疇，另一個教授班我不曉得，不過<font color="#8d2424">郭教官的固定術與長背板就相當紮實，練習要拼到一分半，考試實測要兩分內才算及格（隔壁班聽說是四分）。以個人經驗而言整個流程跑過兩三次差不多就可做到兩分左右，主副手固定後練到反射性的記起來（大約十幾次），省略頸圈調整的十秒（八成的人的脖子都是三指寬），要做到一分二十秒至一分三十秒不會有太大的問題。</font>因為 EMT 考試前晚上不會操體能，所以 EMT 課就會開始代償性的基數遊戲，比如說一組一組叫上來演練長背板，超過兩分就排排站，一起做基數之類的 XD （假如你第一次做就可以達到這個標準，I 服了 YOU，基本上就算你夠快，還是會被找碴挑錯，不然就是被要求跟大家一起做）。\

27\. 三千、繩結與消防學科測驗：專訓第三週的第一天會完成占分發成績 30% 的測驗，要我說的話我認為關鍵絕對在三千公尺跑測。繩結有練，運氣好測到有拴馬結＋雙布魯斯克結的那組很容易滿分（拴馬跟雙布魯有練起來你會發現其實15秒左右就打的完，雙重繫船打十秒，你還有整整一分鐘的時間可以打纏身跟接索結），我大概打1分16左右（應該要打個112比較酷，區隊長檢查的時候會很用力的搖半扣，幸好我都有習慣性地拉緊半扣，雖然繩頭過短也沒被謝區甩掉，呵呵） ，最快的聽說有1分左右，滿分率大約 30% 吧。\
