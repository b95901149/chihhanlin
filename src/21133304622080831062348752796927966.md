## <font color="#3333ff">史洽佛不朽蠻 </font>&nbsp;&nbsp;Tue Oct 23 05:39:41 2012

前言：\
\
這篇心得文的配法基本上純粹好玩，cp 值不見得高，畢竟要湊一套不朽起碼要 1～2e，湊全套不朽的原因純粹是第二章刷鑰匙的時候常常整個綠洲跑 80％ 以上才找到守護者剛好身上的裝本來就有幾件不朽較貴的部份，大概花個千把萬就可以買齊剩下的部位（順便解成就），搭上一個回怒的被動就可以維持 50+12 ％ 額外跑速來跑圖\
\
\
至於史洽佛，當初剛上 1.04 的時候就是靠這把便宜，被動又夭壽強的玩意勉強農 A3&nbsp;農出半套不朽，實在很想知道這把 dot 傷害超高的玩意極限在哪，雖然一把十來萬的史洽佛跟整套兩億的不朽簡直是 LP 比雞腿，說多不搭就有多不搭，不過還是勉強可以組出一套速刷 MP2\~3 A3 或者 MP3\~4 A1 or A2 的裝\
\
\
核心裝備 1: 不朽全套 + 2 被動 （無可饒恕 + 意志堅定）+ 衝刺 （+50％ 跑速符文）\
\
一套不朽與 +25％ 護甲被動大約可以提供 26k 血 （衣服三個洞都插紫寶）、4.5k 護甲、 400 抗與 14％ 近戰減傷，加上無可饒恕與套裝效果每秒回 4 怒，基本上就可以衝刺連放，配個拉庫尼差不多就可以維持 74％ 額外跑速來開圖，沒有任何東西追的上你\
\
\
核心裝備 2: 一把有洞的史洽佛\
\
\
假設除了史洽佛以外其他裝備提供了約 1.6K 力量，那麼市面上常見的三種史洽佛\
\
a) DPS 1400 左右 （+50％ 傷害）\
b) DPS 1100 左右 + 200 力\
c) DPS 1100 左右帶洞 + 70% 綠寶\
\
\
對於這個 build 提供傷害的效果差不多，但是 c) 遠比其他兩樣便宜 ，武器本體甚至不到寶石十分之一的價格，所以要玩這個 build 只要選一把被動發動率 30 ％ 以上便宜的史洽佛即可（超過 30％ 感覺影響不大，幾乎有怪時被動都是常駐的）史洽佛的提供被動傷害差不多 20k /second ，吃爆傷跟生竊，以我為例有 30爆率 +300 爆傷可以提供 20k \* (1+0.3\*300%)\~ 40k 傷害，幾乎跟帳面上的 DPS 差不多，\
\
\
基本上拿史洽佛刷 A3 低 MP 的爽度跟一把 12k dps + 500力 + 250％ 爆傷的斯考恩巨斧相當甚至更優（特地花幾百萬從 AH 拉了一把比較看看），A3 很討厭的媚魔在低MP 的時候基本上不用特地打就會被 20 碼範圍的被動殺掉\
\
\
\
速刷 A3 低 MP 配招：\
\
通常刷 a3 會順便練瘋癲等級，所以我喜歡頭上插紅寶，手上帶獄火 35％ exp 戒假如追隨者也帶一顆獄火戒，剛進 MP2 A3 差不多就有接近 100％ 經驗加成。要速刷基本上建議帶些 dot 大招，比如撕裂 （+9％ 吸血），搭配 406 ％ 先祖鎚原則上精英也死得很快，剩下 4 個主動 1 個被動可以依照個人喜好搭配，假如扛的住一些比較機車的精英可以多配一點攻擊技能，怕被控場可以放個賽亞人或者狂暴衝鋒，太軟可以放萬用怒吼（比如說我不朽以外的都隨便塞一些 MF 或 喬丹石這種偏攻擊型自爆裝），回血不夠可以配回血 +％數 的招，像是霸氣無雙之類的，你會發現 AoE +&nbsp;dot 招連放的感覺一整個就是爽。如果要一邊作其他事情（比如說看個電影之類的）一邊刷白怪煉經驗的話，可以只靠史洽佛被動 + 撕裂 + 一堆防禦型招式跑位站樁就夠了\
\
\
打魔鑰守護者：\
\
基本上無解，也不是說打不贏，用一堆 AoE 招加上低抗低甲的下場就是沒辦法站樁打守護者，最有效率的作法就是把雙手武拿掉，換持劍盾就可以輕鬆推掉\
\
結論：\
\
其實如果不要執著於全套不朽的跑圖效果，用史洽佛配過渡裝來農瘋癲等級應該便宜又有效率，整體 dps 幾乎等於帳面數字的兩倍，可以說是窮人版大根流，用百萬以內的價格輕鬆搞定主副手兩個位置。\

## <font color="#3333ff">劍盾先祖不朽蠻 &nbsp; &nbsp;</font>Thu Oct 25 12:24:38 2012

大家都知道要湊齊不全套享用回怒的特效勢必要犧牲一些部位的優勢，比如腰帶與鞋子就沒辦法選 cp 值更高的來裝，還要犧牲一個被動（無可饒恕）來換取秒回四怒，這個時後如果想持盾會發現 dps 很難往上爬，就算用了現在流行的先祖鎚還是很難打高 MP（MP 8～10）的怪。 這個 build 經過測試可以用來打 A1 MP9 精英怪，除了幾種特殊組合的搞不定（後面會詳述），吃掉一組精英怪的時間大約 2～3 min，吃掉魔鑰守護者耗費的時間差不多，在同樣的裝備下也扛的起 A1 MP10 的怪，不過死亡率稍高（農 A1MP9 鑰匙差不多意外死個兩三次，MP10 搞不好打一組精英就要死一次以上），目前還在研究如何升級這套裝讓他可以農 A2 or A3 高 MP\
\
\< 主動技能 >\
\
戰吼 +20％ 抗性\
戰鬥暴怒 &nbsp;爆擊偶回 15 怒\
霸氣無雙 &nbsp;反彈 35％ 傷害四秒\
狂戰之怒 &nbsp;每增加 25 怒增長一秒變身\
先祖之鎚 &nbsp;408 傷害\
旋風斬 &nbsp;爆擊回 2% 生命\
\
\
\
\< 被動技能 >\
\
\
無情暴虐 &nbsp;5％ 爆率 50％爆傷\
無可饒恕 不扣怒與秒回 2 怒\
奮戰不懈 &nbsp;生命值達 20％ 可減傷 50％\
\
\
\< 裝備需求 >\
\
\
武器使用 DPS 1044 帶 58％ 爆傷的絕截（當然要有死無全屍特效）\
雖然這個 build 的靈感源自於這把我自己覺得很帥的武器，不過換成 DPS 差不多，具備相同等級爆傷且帶高擊回的單手武也 OK防具則要有不朽全套（數值可參考我之前那篇史洽佛不朽蠻）+ 喬丹戒 + 高格檔盾，使用喬丹戒的原因在於我們的目標是精英怪，除非有很不錯的三元戒不然很難製造更好的對精英 DPS 效果，目前市面上增傷 28％ 的喬丹石不到 500 萬，便宜又好用高格檔盾我選用的是 33％ 格檔 225 力 &nbsp;72 體 &nbsp;71 抗 6% 近減 7％ 精英減傷的暴風盾，要用其他的黃盾也可以，以我目前的數據去算 EHP 的話，差不多1 格檔 ＝ 1% 減傷 ＝ 20 體 ＝ 2 % 生命，基本上要挑到近似效果的盾從暴風盾找最容易。\
\
\
整體而言機體的數據是： 1850 力 &nbsp;500 敏 &nbsp;1360 體\
\
64k 血（34％ 額外生命）， 20％ 閃避，33％ 暴率（unbuff） &nbsp;240% 爆傷\
6k 護甲 &nbsp; &nbsp;550 抗 （unbuff） &nbsp;-> &nbsp;7.2 k 護甲 &nbsp; 650 抗 （戰吼 buff）\
秒回 500 （有差不多 350 是不朽手提供的） &nbsp;2.8％ 生竊\
\
攻速 1.55 （unbuff） -> 1.88 (賽亞人 buff)\
帳面 DPS 5.1k (戰鬥暴怒 buff) -> 7.1 k (戰鬥暴怒 + 賽亞人 buff)\
\
\
其中維持 DPS 的關鍵在於爆傷，維持超級賽亞人與無限先祖鎚的關鍵在於爆率，低於以上這個值就很難維持住：這個 build 最神奇的地方在於雖然帳面 DPS 超低，不過搭上無限賽跟先祖鎚以後可以創造出對精英 300k \~ 400k DPH (等效約 500k ～ 700k&nbsp;DPS)，殺掉一隻 5000 萬血的精英差不多就是連續砸個 100 秒就讓他升天，當然實際操作時必須考慮到使用走位回血的緣故，實際輸出的時間可能只有一半，所以處理一隻精英的時間可能長至 200 秒，也就是前文提到的約 3 分鐘\
\
\
\< 技能使用說明 >\
\
假設無怒狀態，先戰吼 +20 怒 -> 戰鬥暴怒 -> 找敵人，通常找到敵人前怒氣會有半滿至全滿，遇敵開始損血後馬上開霸氣無雙與賽亞人，利用旋風斬無視碰撞找到精英怪以後就用先祖鎚 a 怪，攻擊以精英怪為主，僅量不要 a 小兵，血池不穩的時候就開始用旋風斬滾小兵回血，這個 build 利用戰鬥暴怒的符文高速回怒來維持賽亞人，原則上持續以先祖鎚爆擊攻擊時每秒幾乎可回 50 怒以上，只要有 70％ 的時間用先祖鎚輸出就不會有缺怒問題，遇到不能站樁的精英怪組合就必須拉高旋風斬回血的時間，走位到怪物群的邊緣使用先祖鎚 a 某支小兵，成功 a 死就能靠死無全屍特效 + 腰帶生竊的效果直接回滿血條，使用奮戰不懈被動的目的就是要配合絕截的特效來降低撤退時的死亡率，把所有小兵視為無冷卻的超強生命藥水來用；瞬間的回血首先仰賴先祖鎚傷害的生竊，大約 600k (DPS)\* 2.8% \* 0.2 \~ 3.4 k 秒回血，換句話說相當於 2.1 k 集中回復 &nbsp;1.6 攻速 的效果，如果使用帶生竊單手武很容易讓這個數字倍增：假如使用旋風斬刷單一目標的話大概生竊效果只有二十分之一或者更低（旋風斬傷害跳一次大概 30k 而已），主要還是靠 2 ％爆擊回血，如果同時攻擊的目標夠多的話（大約 5～6 個以上）回血效果會大於先祖鎚生竊。\
\
\
\
實際操作經驗霸氣無雙沒作用的時候其實上述的回血沒辦法維持血條不降，所以整體操作的重點在於如何適當地躲過霸氣無雙的冷卻時間，由於先祖鎚幾乎必爆擊 （33％ + 賽亞人 10％ + 戰鬥暴怒 3％ + 怒氣池 100 怒 ～ 20 ％ = 66%），假設一秒爆一次，霸氣無雙無作用的時間大約 (12s - 4s)/2 = 4s 左右，有霸氣無雙 35％ 減傷的情況下靠逆天的先祖鎚回血幾乎可以鎖血扛兩樣以上的地板技（比如瘟疫加熔火），只有四秒的空檔需要走位回血；若是使用絕截的死無全屍特效則可以大幅提昇這四秒的生存能力，特別是精英怪附近白怪太少，沒辦法使用旋風斬回血的時候。若使用其他擊回或生竊單手武則通常有兩種情況：回血能力夠，站樁把怪殺掉；回血能力不夠，在沒有大量白怪當血庫的時候拼命堆屍，通常對上 MP10 的機車精英怪都有這種現象。\
\
\
\< 精英怪技能應對 >\
\
\
無腦站樁典型： 勇士之陵、李奧瑞克宅內部\
這一類常有十隻以上白怪可以刷血，沒有特別技能絕對殺不掉劍盾不朽蠻\
\
\
低危險度精英技能： 幻象，所有控場技，比如禁錮、築牆、冰凍、漩渦\
放入超級賽亞人有很大的原因就是要免疫控場技，在霸氣無雙無作用的時候一但被控到場通常就是被秒殺，所以這個 build 必須依賴解控場技來降低死亡率\
\
\
中危險度精英技能： 地板傷害技、火鍊等等\
一般來說這個 build 的回血量足以支撐同時擁有兩個地板技的精英怪傷害，假如有三個以上就比較難維持一次超賽就把敵人擊倒，因為你必須花較多時間來設法回血\
\
高危險度精英技能： 火球、傷害反彈\
\
\
前者會影響撤退補血的流暢度，容易錯估撤退血量，後者好像會被死無全屍效果影響（不是很確定），不過測試時遇上傷害反彈的怪打起來感覺比較抖，其實也不太容易死\
\
\
\
\
無解精英技能： 秘法光束\
不用旋風斬走位幾乎沒辦法打，太容易斷怒，這個時候被控到場一定死只能說無解，要殺掉這種精英通常自己要死個好幾遍才行\
\
\
其他沒提到的精英怪類型比如護盾、強命之類的基本上沒威脅，純粹拉長宰殺時間；另外如果精英怪併團，假如地板技太多比較容易死，視情況而定\
\
\
\
\<打 A1 魔鑰守護者>\
\
\
基本上很簡單，掛上霸氣無雙用先祖鎚硬 a，超賽免疫禁錮，扛不住到附近找小怪回血後繼續打就行。唯一種無解的狀態是同時拉了高危險度精英或無解精英或者&nbsp;4 &nbsp;隻以上的樹妖 + 蠻牛（衝鋒獸），前者不解釋，後者則是因為一但失去控場免疫，想要靠近怪物團就會被牛撞開 ，傷害又夭壽高，樹妖跑太慢沒辦法拉怪單獨分離出守護者來打，毒傷又跟精英怪的地板技有得比。\
\
\
\< 結論 >\
\
這個 build 原本是因為打到一把爆傷絕截，肖想用它來農 a3 高 MP (20% 對惡魔傷害很誘人，先前使用史洽佛的嘗試因為回血能力不足到 MP5 以上就宣告失敗 )，本來想把這個 build 命名為絕截不朽蠻，不過考量到絕截特效加生竊幾乎就是個 bug，未來很有機會被修掉，使用絕截只是要提高 4 秒霸氣無雙冷卻空檔的效率而以，換成其他單手武也未嘗不可，甚至拔掉不朽改用重武回怒也未嘗不可（只是可能要再犧牲一個被動），相較於雙手先祖或雙持先祖需要依賴高生竊與高 DPS，劍盾先祖流依賴爆傷與大量增傷技能與不斷怒無限賽亞人來製造足夠的輸出，可以用較低的價格取得足以扛住 MP9\~10 的血甲抗和回血能力，除去哥不林永遠殺不掉與少數精英怪無解的缺點以外，應該有相當的潛力（其實我只是想推廣暴風盾而已 XD）\
\
\
\
以上就是我開發的劍盾絕截不朽先祖無限超賽蠻，簡稱劍盾先祖蠻，帳面 DPS 只是假象\

我的配裝跟技能配置基本上以不朽套裝為底，用改版後非常強力的先祖鎚搭 406％ 傷害符文作為基本輸出，利用單持劍盾的高甲與格檔優勢稱出不錯的等效血量扛住高 MP 的精英技能傷害，使用配合先祖鎚的無限超賽來持續免疫所有控場形精英技能直至精英怪死亡；由於需要不斷怒的特性，所以必須綁定無可饒恕（回 2 怒加不耗怒）與戰鬥暴怒配一觸擊發符文（爆擊機率回 15 怒）。通常高 MP 的白怪不容易死又會擠一大團，為了走位方便使用旋風斬來調整攻擊角度與目標（主打精英怪），使用集血斬符文來加強回血技能（坦地板傷害）。霸氣無雙配合制敵機先符文可說是 1.05 版戰吼被改弱之後最強力的減傷技能（4 秒減傷 35％），可以增加操作寬裕度，事實上並不是必帶的技能，假如可以將生竊由不朽腰帶的 2.8 ％提昇兩倍至 6％ 左右（被動插 3% 吸血或者選擇與以以下範例 DPS 差不多，」帶生竊的高攻速單手武）便能拔掉這個技能，改裝衝刺來製造雙旋風跑蠻效果，如此一來跑圖的速度也會更快。\
\
\
帶戰吼的出發點在於克制 A3 媚魔的減防效果（吃招幾乎可扣 3000 甲，加戰吼帶來的抗甲效果可以扛住被扣防的虛弱期，足以在血池見底前先殺掉媚魔），同時 20 產怒效果相當於 4％ 先祖槌爆率，可以即時補足怒氣池來維持超賽時的爆率。\
\
\
被動中的無情暴虐基本上建議必裝，因為無限先祖爆擊蠻的輸出就局限在爆傷，爆率只是作為啟動與回怒的作用，真正在輸出時一定是以接近 100％ 爆率在輸出（基礎爆率 40％&nbsp;+ 滿怒 20％ + 超賽 10％ 就差不多 70％），迷信的 20％ 減傷對於扛地板技很有用，不朽套件與暴風盾提供了將近 20％ 的近戰減傷來扛大量白怪傷害，剩下精英怪製造的遠程與元素傷害用迷信補足剛剛好，同時回怒特效對於這個 build 的容錯程度也有很大的幫助。

![图片](/uploads/8/4/4/0/8440048/2831018_orig.jpg){@style="width:100%;max-width:908px"}

裝備說明：\
\
\
身為布爾凱索的子孫，弄套不朽王套裝來致敬是必需要的 嚴格說起來不朽頭、不朽身與不朽手都算高 CP 值的部位，湊成五件主要為了回怒效果，最低限度維持永動旋風斬或者無怒時可以快速開啟戰鬥暴怒。假如操作技術足夠不缺怒也不見得要湊全套，腰帶可以換成好的悲慟來增加輸出，或者更有錢一些可以用巫異時刻，鞋子可以換高抗高主屬鞋。我這套不朽當初買大概要 2E (美服)，其中 80％ 的成本都落在頭與身體兩個部位，而對\
於其他流派的野蠻人來說這兩件應該也是高優先度的採購目標，所以我相信大部分小有積蓄的老手野蠻人朋友可能都已經取得這部份的裝，接著只要花點小錢就能享受這個&nbsp;build 。我選的不朽手是千萬直購拉來的，帶高力爆傷的攻擊型太貴，反而這種帶敏的有不錯的加閃避效果又便宜。<br />

![图片](/uploads/8/4/4/0/8440048/2103085_orig.jpg){@style="width:100%;max-width:871px"}

劍盾蠻最大的好處便是副手便宜。\
\
1.05 低傷害的時代到來，過往坦蠻三神器之一的暴風盾已經淪落到幾十萬暗黑幣路邊貨的程度，選盾很簡單，前述抗甲下簡單用 1 格檔 ＝ 1% 減傷 ＝ 20 體 ＝ 2 % 生命，基本上要挑到與我範例的裝有近似效果的盾從暴風盾找最容易（我這顆幾百萬而以）\
\
武器的選擇則挑了絕截這把很有趣的傳奇劍，死無全屍特效搭生竊可以將白怪當血球（也許要被修掉了），對惡魔 25％ 傷害很適合農 A3，在 AH 上花點時間可以挑便宜帶爆傷的絕截，絕對是千萬以內甚至不到百萬便能取得的好劍。\
\
\
單手武的 DPS 上限低，搭盾打 MP10 精英實在不太夠用，所以這個 build 單刷幾乎是綁定喬丹石，挑一顆對精英增傷近頂的（27～29％）也不需破千萬，至於另外一顆戒指則最少要雙爆，找帶高體的便宜又好用。基於對爆傷的追求，護身符也選擇高爆傷，主屬力體儘量挑高的，不加帶爆率全抗的主屬高爆傷護符，我這顆僅僅五十萬直購價。唯一要注意的是一旦護符不帶爆率，護腕就必須選帶爆率的才保險，我挑的拉庫尼純粹貪圖跑圖方便（這個自己打到的，帶爆的拉庫尼都天價，CP 值不高），用一般的高體抗帶爆就可以了。最後褲子與肩甲隨便挑高力體抗的就可以，深淵褲帥氣又符合需求，缺點是有點貴，肩甲假如能帶拾取最好，預算不夠路邊貨也行（140 力 140 體 60 抗五十萬有找）。\
\
與其把這個 build 叫劍盾先祖蠻，我覺得的叫成絕截不朽蠻更有殺氣些（可惜絕截跟不朽套件都不是必要元素，反而會限制這個流派的 DPS 發展）\
\
\
最後還是要談一下如何施放這個技能組：\
\
戰吼與戰鬥暴怒常駐，放先祖鎚通常可維持怒氣池半滿 ，無盡旋風斬用來無視碰撞走位，遇到媚魔一定要先砍掉。遇到精英怪可以開超賽先祖鎚連擊，純先祖鎚連擊只要同時擊中兩個目標以上戰鬥暴怒的回怒效果就可以無盡超賽，偶爾需要靠旋風斬調整攻擊位置保持複數擊中或者回血，霸氣無雙用來對付多地板傷害技的精英以便維持站樁，這個看影片應該就能學起來。走位靈活的人有霸氣無雙可以拔戰吼改放忘卻痛苦，基本上可以撐過霸氣無雙冷卻期或者防備媚魔與特多秘法光束的攻擊。拔掉霸氣無雙放猛擊可以無痛回怒順便加 DPS (選可疊三層 8％ 技能傷害的符文)，放狂亂天襲同樣可以增加 DPS 並維持回怒。\
\
一旦先祖鎚吸血跟敵方傷害達成平衡其實就用不著各類啪數回血技能，甚至絕截的死無全屍特效也沒有什麼機會放，只有血抗甲扛不住的時候才需要這些保命手段。範例配裝其實血配的太多，能不能順農的關鍵在於質（EHP/HP）而非量（帳面 HP），技術越好的人越不需要依賴這些降低死亡率的手段（霸氣無雙，回血斬等等），可以儘量往衝高 DPS 的方向走，不過要有花大錢的心裡準備，這樣一來還不如直接配雙手撕裂蠻甚至是旋風先祖蠻。\

這個 build 大概全刷兩三次 A3 才配好並完成測試，A1、A2 應該也不會有問題，原則上可以作到 MP10 A1+A2+A3 疊五打鑰匙在一個小時內完成，如果是刷 MP8\~9 絕對快上許多。類似的技能樹試過單刷 MP7 紅門只有庫勒那組推不動，其餘的都可以在 10 min 完成， 3E 的套裝成本絕對值回票價。如何在不花大錢換裝的期況下單刷更高 MP 紅門仍在研究當中，希望有更多蠻子加入這個流派來找出配裝極限，有興趣可以加我好友：\

標題提到的平均 12 min 來說可以縮得更短，這裡的配技重點在於空出一招被動與一招主動來放置打紅門技能，刷 KEY 裝的布爾凱索的恩惠除了增加續航力，並沒有實際防禦或攻擊加成，衝刺更可以換成強力一點的防禦技或者回怒普攻，單挑的時候會強一點\
\
\
路線講解：\
\
為了縮短找守護者的時間，一定從悲慘之原起手，遇到精英就清掉，找到守護者之後記下位置傳到腐潰之林（必帶先祖與勇士兩組精英）與李奧瑞克宅（屋內屋外至少一組）或者墓園疊滿需要的涅法雷姆之勇，最後回去打守護者。\
\
由於帶了衝刺，根據配招可以選擇跳過難打的精英（比如勇士之陵遇到秘法 + 褻瀆 + 反傷用 A 配法幾乎啃不下去，遇到強命帶多地板傷害或者鬼魂精英會讓你斷賽亞人的嫌打太久也可以跳），加速疊五的時間。不管是 A 配法或者 B 配法，基本上都儘量透過賽亞人 CD 時間跑圖找精英來縮短整體耗時。\
\
A 配法的好處：\
\
這個裝吃掉 MP7 怪（1000W\~2000W 血量）的速度很快（小於一分鐘），如果對圖夠熟，基本上找精英的時間很快，所以用布爾凱索的恩惠可以減少等待時間。不過浪廢掉一個被動技對攻擊或防禦面的衝擊很可能讓一些機車的精英怪推不掉或者難打，比如說打守護者就不容易維持超賽打完（DPS 太低），操作不夠強的人很容易死亡率驟昇。另外這個配法如果不拔掉衝刺，打 MP8 以上或 MP7 以上紅門應該會扛不住傷害而吃土，所以是 MP7 限定，用來增加刷 KEY 效率與自虐練走位的方法。\
\
\
B 配法的好處：\
\
廣義的 B 配法指的是剩下那格被動不塞布爾凱索的恩惠。如果放了武器大師傷害變得很夠，守護者好打許多。其實對於喜歡撿黃裝享受鑑寶摸彩的人來說，超賽多餘的冷卻時間正好用來鑑定賣裝，雖然帳面打 KEY 時間好像有變長，其實效率更好。裝不夠好的人被動這格也可以塞吸血 3％（武器沒吸血，或者想打 MP8 以上站樁），或者塞迷信來增強防禦與回怒。\
\
\
\
結論：\
\
這個配法主要著眼於不論是單刷或者多人打紅門都必須預留一些招式來調整攻防比例，單刷時甚至有加入控場型技能必要，所以留下兩招自由發揮空間。單刷紅門我認為拔掉超賽改放猛擊（符文 +8％ 傷害可疊三層）可以維持足夠的等效 DPS 打 MP7 紅門（僅限骷髏王組與岡鉧組）而不至於讓 boss 狂暴，不過 MP8 以上控場型精英會變得很難打，所以我很猶豫這個技能要不要拔。另一個打紅門庫勒組很沒效率的技能是旋風斬，不拔掉的原\
因在於這個技能打精英跟紅門骷髏王組與岡鉧組太好用，堪稱走位神技，容錯率高，要拔掉它大概只有增強回血能力一途（武器吸血是一定要的，被動可能得綁定激勵風加秒回血或者吸血 3％，再加上奮戰不蠏也許有機會扛住傷害）。要拔掉旋風斬一定要另找一招走位主動技比如躍擊或者狂暴衝鋒，前者可配控場符文，後者有機會取代超賽作為解控場技使用（不過還是有少部份控場不能解，時機方向距離抓錯會更危險），但抗甲不夠的機體對上超多怪 + 秘法光束若沒有旋風斬根本死路一條，所以這個技能要不要拔，或者說能不能拔我也很猶豫 XD\

## <font color="#3333ff">先祖蠻速刷 MP10 先祖特化技能組</font> &nbsp; &nbsp;Fri Apr 19 01:43:48 2013

![图片](/uploads/8/4/4/0/8440048/104338_orig.jpg "unbuff DPS 約 12W （含被動武器大師 + 無情暴虐）"){@style="width:100%;max-width:1100px"}

![图片](/uploads/8/4/4/0/8440048/3822598_orig.jpg "技能全放面板 DPS 大概 23 W，純 406 先祖來輸出"){@style="width:100%;max-width:1100px"}

unbuff DPS 約 12W （含被動武器大師 + 無情暴虐）\
\
http://truth.bahamut.com.tw/s01/201304/872b29465c86efc680f1ba6905119a7d.JPG\
\
\
技能全放面板 DPS 大概 23 W，純 406 先祖來輸出\
\
http://truth.bahamut.com.tw/s01/201304/f21c9410adcb7f833dd4de34812e0112.JPG\
\
\
\
裝備大概千萬級（依照先前版上幾篇配裝指南很容易配出差不多的裝）\
生竊有腰帶 3％ 就夠了\
\
劍盾換成百萬左右的雙手斯考恩大概 unbuff DPS 會有 15W up，依然可以不斷超賽先祖（僅限於白怪密度高的先祖），不過進場的死亡率比較高，換成雙持也可以，不過也會有死亡率偏高的問題。同樣防具配百萬級的日光守祭 unbuff DPS 約 9W （從打寶的觀點來講可能比較有效率），用便宜的喬丹戒取代火戒可以稍微降低一點打精英的時間，這個要根據每個人實際狀況來調整配戴。\
\
\
\
技能配置：\
\
\
被動： 無情暴虐 + 武器大師 + 爭戰者\
\
主動：\
\
&nbsp; &nbsp; &nbsp; 超賽 406先祖鎚核心技能組\
\
&nbsp; &nbsp; &nbsp; 左鍵： 406％ 先祖鎚 &nbsp; &nbsp; &nbsp;右鍵：狂暴衝鋒 （減 CD）\
\
&nbsp; &nbsp; &nbsp; 戰鬥暴怒 - 一觸即發\
\
&nbsp; &nbsp; &nbsp; 狂戰之怒 - 無盡之怒\
\
\
\
&nbsp; &nbsp; &nbsp; 維持生存技能組\
\
&nbsp; &nbsp; &nbsp; 撕裂 9％ 轉生命\
&nbsp;\
&nbsp; &nbsp; &nbsp; 霸氣無雙 35％ 減傷\
\
\
\
打法：\
\
\
利用狂暴衝鋒移動灌滿怒氣池（選用減 CD 符文的好處），基本上就可以啟動超賽先祖鎚的技能組，利用狂暴衝鋒移動到精英怪前一刻開超賽，左鍵就可以按著不放純先祖輸出，接著撕裂與霸氣輪流按就能確保足夠的回血（大約 4～5 秒 放一次）假如你的防禦面夠好，霸氣無雙符文可以改成 +10 爆率，輸出夠高可以將無盡之怒換成 100％ 增傷符文來試著秒精英怪。\
\
\
\
\
\
這個 BUILD 相較於個人先前用的劍盾先祖配置主要在於拔掉防禦回血型的被動，為了提高輸出與清群怪能力綁定爭戰者。戰吼產怒與旋風斬走位的功能可以使用狂暴衝鋒來取代，空出來的一格技能可以放降低裝備吸血％數要求的撕裂來使用。由於防禦面薄弱，所以還需要霸氣無雙的減傷效果來提昇站樁能力。\
\
\
\
\
原則上這個配置最容易死亡的部份發生在走位切進精英怪前變身的時候，一定要確保撕裂效果常駐才能切入怪群核心，否則容易被秒。另外遇到帶祕法復合高傷害地板技能的精英不能硬打; 用這個技能組可以將實際輸出常態維持在 10 倍 unbuff面板 DPS，以我的裝來說差不多有 100W+ 如此刷完一趟 MP10 先祖墓穴約2\~3 min，80％ 的精英組合都可以很順地打完。\
