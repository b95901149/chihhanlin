121T 後適用\
\
1\. 受訓天數：自 121T 以後替代役新訓（軍事基礎訓練）的天數縮減至 15天（不包含新訓結束、撥交前的六、日週末結訓假），與以前相比，少了兩天訓期和一次懇親假。乍聽之下好像訓期減少很爽，實際上非常痛苦，<font color="#a82e2e">少了懇親假你就沒辦法在役別甄選前回家好好調查打聽應屆梯次各種役別的優缺點，也沒辦法自己印期末鑑測題庫（替代役法規與考古題），也沒辦法補充加購生活必需品，</font>體力不佳的人也沒辦法加大自主訓練的力度（休息的時間不夠）。\
\
所以 121T 以後的替代役男入營前最重要的一件事，便是儘量在入營前準備好一切你可能用到的東西，全部給帶到成功嶺上（帶到不能帶的就是入違禁品櫃而已，不用擔心，喉糖多到滿出來就借鄰員的內務櫃放，他一定很樂意）\
\
2\. 入營日： 照著徵召令上指示的地點準時集合，報到後會有多縣市議員來精神講話，發發紀念品之類的，地方政府也會發放具備地方特色的贈品給役男（電話卡、手提包、捷運卡）。搭上火車以後還會獲得一罐礦泉水與鐵路便當一份。\
\
3\. 入營報到： <font color="#8d2424">夏天入營的時候，陽光相當毒辣，建議自備鴨舌帽（結訓穿便服的時候不能戴公發帽，所以入營的時後用不上，結訓的時候也有機會戴）。</font>填資料的時候不用動腦，上頭說一句，你寫一句，不懂就舉手，這個就是新訓 SOP，切記不要自作聰明，隔壁做什麼你作什麼就對了。\
\
\
4\. 理髮： 基本上除非你的頭已經理到接近光頭，不然一定會在這裡再嚕一次。假如你頭上有青春痘或者受傷的地方，或者頭皮很敏感怕痛才建議在入營前理髮完畢。\
\
\
5\. 入營生活用品採買：<font color="#8d2424">建議內衣褲至少多買一套</font>，因為晚上發衣服的時候一定有人會因為缺貨拿不到（通常 L size 最熱門），洗衣袋也最好多買，你用不到還可以借給別人用。爽身粉見仁見智，我就不是很喜歡。<font color="#8d2424">最後假如你身上沒有喉糖，拜託順路走到隔壁的 OK 買個一兩包備存，上述所有東西只要你為人正直、臉皮不薄，統統都可以跟同袍借來檔，唯獨喉糖這項隨著時間接近結訓，越容易缺貨。</font>\
\
\
6\. 編隊：通常一個中隊約百人，編成 10 來個小分隊。身高越高的人越容易成為排頭，越矮的越容易成為排尾（敝人就是）。排頭通常需要多承攬一些小型業務，發口令之類的，排尾則是常常需要移動位置回補隊伍。集合隊通常有四種，第一種稱為方隊，就是依照分隊來排序，1至5 分隊在隊長左手側（這樣的形式稱為一個方隊），6 至 10 分隊在右手側，集合完畢通常會進行分隊點名。第二種為不按建制，形成五個班，向右向前排尾依序補齊。所謂的班就是列的意思，這種隊形要求一行有 5 人 （完整的 5 個人稱為滿伍），只有右手邊的排尾可以不滿伍，同時最後一個滿伍的最末員（一行的最後一個人）必須回報<font color="#8d2424">：『報告值星分隊長，五班 XX』，XX 可以是缺一、缺二等等，如果沒有缺人 XX 就是滿伍，而不是缺五。</font>這種隊形主要用在隊伍行進，進餐廳前的編組。第三種為縱隊，很像是第一種方隊的變形，第一個班（列）為第一分隊，第二個班為第二個分隊等等依序排至最後一個分隊，你會發現左邊第一行會由所有分隊的排頭組成。最後一種稱為講話隊形，就是隊伍排成 ㄇ 字行圍繞隊長，這個時候比較常聽到的口令是：<font color="#8d2424">『九伍正面』或『七伍正面』</font>，這個口令的意思與第\
形成五個班、形成四個班之類的口令很像，後者限制一行（伍）的人數，前者限制一列（一個班）的總人數。這個時候第一個班（直接面向隊長的最前列）必須由右至左依續報數至規定的最末伍（七、九或者其他指定的數字），剩餘的人才有辦法往後補位對正。這種隊形通常用在早晚點名，宣佈重要事項的時候。\
\
\
\
覺得上面太煩不想看只要記得一點：<font color="#8d2424">不論何種隊形，跟著自己分隊的人移動就對了。</font>\
\
\
7\. 洗澡：通常有共浴的大澡堂跟隔間兩種，<font color="#8d2424">個人推薦大澡堂，快速又可以洗很久。</font>大澡堂的蓮蓬頭數量大概是隔間的四倍，又容許共用（一個抹，一個沖），所以幾乎隨時有空位可以補位洗。我所屬第三中隊晚上盥洗時間會放宮崎駿的音樂 CD，我每次洗的時候通常都可以從豆豆龍洗到兩三首以後的魔女宅急便，冷熱交替多沖個幾次，舒展筋骨，我估計躲在角落洗個半小時也不會有人催。\
\
洗大澡堂的時候肥皂盒放背後，離牆遠一點比較好，不然很容易被累積水流飄走，講一些有點尷尬的台詞（我第一天就不小心讓肥皂盒飄走了，講完台詞覺得挺好笑的）。\
\
假如你很害羞，不喜歡跟別人坦誠相見，還是有機會洗到大澡堂；有一次不曉得鍋爐故障還是其他原因，導致大澡堂只有冷水，隔間只有熱水，科科，你覺得哪邊可以洗？\
\
\
8\. 用餐禮儀：進餐廳的時候要喊『責任紀律』，配合立正、向右轉（兩動），稍息四個動作。隊長喊『一路』，我們喊『服從』，最後花個幾分鐘讓全部人進餐廳。進餐廳直到開動前後還有一系列的分解動作，跟著其他人做就對了。用餐基本上要以碗就口，手腕不能靠在桌上，不能站立（搆不到湯碗請鄰員代盛），<font color="#8d2424">跟隔壁的聊天要低調</font>。雖然現在已經不會嚴格要求，但是被最前桌副中隊長以上的長官盯上會有點可怕（大多數地情況也只是罰站，口頭申誡一下，其實也不怎樣）。<font color="#8d2424">不過請記得，新訓一週後餐廳的電視就會打開（享受與世間相連的感覺），太沒規矩的話小心往後幾餐沒電視看。</font>\
\
\
9\. 餐點品質：以個人來說，我覺得還過得去（大勝台大男一ㄆㄨㄣ城），畢竟早餐預算只有 17 元，午晚餐 40 元，雖然肉少了點，但是蔬菜類調味都不錯，基本上屬於高纖高鈉，扒上兩碗飯不會有問題的菜色，每餐還附帶一鍋不同口味的糖水來幫助回覆體力（我最喜歡薏仁漿、豆漿跟喝起來有點假的奶茶）。雖然感覺得出來味精下很多，但是以白天運動的出汗量來講我覺得補充電解質剛好。\
\
\
<font color="#8d2424">成功嶺裡的菜相當有梗，這裡的梗是字面意義上的梗，</font>可以訓練你的使用筷子的技巧；很多人不喜歡吃菜，有的時候早餐主食出現板條、詭異烏龍麵、油到爆鹹粥的時候我會搜刮同桌的空心菜來吃（等到可以出去加添飯菜的時候通常有點晚），吃個四五盤基本上到中午都不太會餓。除去幾乎每餐必有，看起來像蔥段，極富嚼勁的深色蔬菜外，其餘配菜大部分都煮得非常軟爛，比如我曾經把筍子誤認為杏鮑菇，這種類型的配菜我最喜歡的是<font color="#8d2424">奶焗馬鈴薯佐培根</font>，非常好吃，就算冷掉也很夠味，加添菜的時候記得去多撈點。\
\
\
<font color="#8d2424">秘技：利用不按建制隊形刻意排到排尾有很大的機率可以最後進餐廳，這個時候有很高機率被分配到不足員的餐桌（少於六人），這個時候可以輕易獨占大量甜湯。想要找特定人偷聊天也可以用同樣的方式一起補到排尾（不建議，我比較喜歡跟不同人坐，聊起來比較有趣）。收拾餐具的時候請隔壁桌的同學一起幫忙即可。</font>\
\
<font color="#8d2424">微秘技： 菜渣集中時用飯匙最快也最安靜。</font>\
\
\
10\. 就寢：一般而言 21:45 要床前報數（通常這個時候音樂會放到娜烏西卡），21:50-22:00 床上定位，<font color="#8d2424">22:00-23:00 宵禁（不准下床上廁所），05:30-06:00 晨禁</font>。除了緊急情況以外，晨宵禁的時候通常禁止下床，偷聊天倒是可以，前三天因為大家還不熟所以不會很吵，適應期一過常常有人聊天聊到半夜，太吵的時候區隊長會出來罵人（結訓前管制最嚴）。<font color="#8d2424">被警告的時候謹記事不過三的原則，兩次警告以後就真的不要再講話了，</font>不然應該有機會被叫出來罰站。\
\
\
床位大約兩個肩膀寬，剛開始睡得時候翻身有可能會肘擊隔壁床友，不過睡過幾天就會自己適應空間大小，眼鏡怕壓到可以放到蚊帳上方。另外<font color="#8d2424">由於床位緊密相鄰，晚上睡覺通常不會帶口罩，所以一有人感冒很容易過個兩天同床上下鋪 8 個人全部中鏢，</font>所以請好好保重身體。\
\
\
<font color="#8d2424">秘技：上鋪通常比較涼快（半身可以被電風扇吹到），下舖則是移動比較方便。</font>上下鋪私自對調基本上沒什麼問題（要正式對調床位就需要向隊長報備，因為會影響內務評分）。\
\
\
<font color="#8d2424">秘技：床墊底下可以塞任何你想的需要用到的日用品（只要你塞的下），比如隔天著裝需要的軍襪、號碼衣等等，</font>因為早上必須在五分鐘內集合，所以提早幾分鐘醒來在床上換好衣服可以讓你有更多的時間悠閒地上廁所，喝個水之類的。\
\
\
11\. 三千障礙：06:15-07:00 的時間要在成功嶺裡小小地跑上一圈，<font color="#8d2424">假如你可以跟著隊伍在二十分左右跑完，或者可以一路跑到介壽台附近才脫隊的話，恭喜你期末鑑測絕對沒問題，因為這個路線充斥各種爬坡，能維持速度代表你的肌耐力足夠。</font>對於體力較差的人也不用擔心，喘不過氣或者快抽筋的時候隨時可以退到旁邊用走的（還有一大批拿著氧氣罐的勤務役男監控，最後面還有一台救護車）。期末鑑測前大約會跑將近十次的三千大越野，所以慢跑苦手的人（比如我）必須善用這段時間訓練心肺機能與肌耐力，配合體適能課學到的肌力訓練（大腿、小腿），我從 25+ min 進步到 22 min （雖然沒有滿分，但是也拿到到七十，考慮到我的腳長比別人短上 10%，我勉強可以接受，至少跑到預定的目標），跑完肌肉也不會酸痛。只要注意不要在鑑測前感冒就好。\
\
\
<font color="#8d2424">秘技：如果有機會，入營前花一個禮拜練跑三千會比較好（我只騎單車，只練到大腿 Orz ... 不然我覺得多跑一個禮拜我可以跑進 20 min）</font>\
\
\
<font color="#8d2424">秘技：跑得慢的人可以請跑得快的人幫忙整理部份內務（通常跟不上隊伍的人會被集合，慢 5-10 min 後才一起帶回寢室），這樣才會有足夠的時間做伸展操放鬆肌肉。體力越不行的人越需要作好收操的部份，才有辦法加大訓練力度也不會導致隔天肌肉酸痛。</font>\
\
\
假如你跟我一樣肉腳，擁有超大鮪魚肚與 BMI 的話，一開始可以先避開上坡，用平地持續跑來練心肺，感冒換氣不順可以用全程競走的方式來練習，乖乖走自己的路不要講話，也不會有人逼你跑。<font color="#8d2424">體適能教了肌力訓練（小吳老師教的那一套，深蹲、弓箭步練大腿，墊腳尖，原地跳躍練小腿；有餘力還可以連核心肌群的動作一起做，不過要小心做過頭會導致隔天跑步很痛苦，因為上半身會隱隱抽痛）利用午休，睡前的空檔持續做上 15 min 以上（至少要作到酸麻感出現），結束時適當按摩、伸展肌肉，配合軟膏、肌樂之類的藥物輔助通常可以避開肌肉酸痛的現象。</font>\
\
12\. 整理內務：折棉被、蚊帳等等隊長都會教，<font color="#8d2424">這個部份盡力就好，也不用花太多力去做，要靠內務加分基本上吃運氣</font>（全新毛巾有可能被評氾黃，床底臉盆有可能被踢歪，亂折的棉被也有機會被打圈，因為上鋪看不到後面側面加底部四個面的瑕疵，有些舊蚊帳你不偷塞電話卡絕對折不成豆腐）。大家都聽過賣油翁的故事，所以熟練以後整理的速度會越來越快，無聊有閒的時候可以用心折，時間不夠的時候大致折出雛型，硬捏出兩個角跟兩個平整面就好。\
\
\
<font color="#8d2424">假如你當過大學課堂</font><font color="#8d2424">人數多的助教，應該都知道這種例常性評分都是抓表現最差的出來鞭，所以最後會因為內務被罰勤的通常都是最誇張的兩三位而已，其他人都會透過全體加扣分的手段調回基準線，所以真的不需要太看重</font>，除非你真的很在意總成績（內務的一個圈大概換算成總成績額外的 0.00X-0.0X 分而已，把時間投資到讀法規上準備筆試還比較有效率）。\
\
\
\
<font color="#8d2424">秘技：真的折不好賄賂或哀求鄰員幫忙就好，除非你真的作人太失敗，不然都找得到人幫忙。</font>\
<font color="#8d2424">秘技：各項雜物放進鞋盒，塞到內務櫃後方內側基本上就算整理好了。</font>\
<font color="#8d2424">秘技：檢查用的衛生紙另外準備一包全新的不要拆，這項檢查基本上也不用花時間了。</font>\
\
\
13\. 基本教練：稍息、立正、向左向右轉，向後轉，然後就沒了，鑑測也只考這些。<font color="#8d2424">向後轉大概是最難的，只要記得右腳退，右腳收，雙腳跟為支點旋轉，每動結束時腳尖著地就可以做好這個動作。稍息立正時眼神直視前方（找個遠方目標物一直看就可以），空洞一點也無妨；舉手答有時直上直下，大臂貼耳際基本上就不會被刁。</font>\
\
老實講我覺得這些動作沒麼難度，高中軍訓就教過了，最痛苦的反而是頂著豔陽，保持正坐的姿勢坐在板凳上看其他分隊操演。\
\
14\. 體適能課程：通常有兩堂會跳有氧（老師好像是某年亞運還什麼運動會的跆拳道銀牌的馬尾姊姊），第一次上大概是鄭多燕等級，第二次就會稍微提昇強度，有一點點戰鬥有氧的感覺。另外會有兩堂小吳老師帶的課，主要做一些增強肌力的動作，有鍛鍊爆發力的，暖身的巴西操，也有練核心肌群（時下很夯的人魚線），大多屬於比較慢速的動作，做完肌肉會明顯酸漲的那種。最後還有一堂是軍歌比賽，基本上不太耗體力。\
\
<font color="#8d2424">我個人認為成功嶺體適能教得很不錯，假如你每天都有撥時間複習這些動作，對於肌力的提昇很有幫助（假如你身強體健，三千都跑 15 分以內那大概這些運動的強度稍嫌不足）</font>。上課的時候假如剛好在徒手三千跑步的前一天的話，就不要刻意增加有氧的強度（減少跳的動作），做操的時候會有一個戰鬥阿嬤走來走去抓態度不夠認真的，多注意一點就不會被抓到台前 XD\
\

31\. 成長探索營： 基本上包含四大項目，需要合作的低空、高空項目與攀岩、垂降等等。會被排到哪一天不一定，因為一天通常只能容納四個中隊，上午玩高低空的，下午就來攀岩垂降。要注意的地方在於是每個人都有機會同時操作到高空主項目、攀岩與垂降（低空要團隊合作，所以都會參與，高空不敢爬的就是當地面確保小組）。基本上手腳無力的就不建議攀岩或超難的高空項目，因為你也爬不上去，通常就掛在一兩層樓高的半空中準備喊降落而已。成功嶺的此類設備在全台灣算是數一數二好的（高低空項目加一加有 21 項），據說想在外頭玩到其中的一兩種高空項目都要不少新台票，既然是國家給的福利，就放開心來玩吧。\

秘技： 進成功嶺以後你知道公發水杯的 O ring （塑膠透明防水環）非常容易不見，不過你很容易在攀岩場撿到一托拉庫的備品，撿幾個洗一洗放回百寶箱備用，撥交那天就不用擔心裝水的水杯放黑袋會漏水（很多役別規定要帶公發水杯）\

秘技：高空如果有機會分到獨木橋或空中飛人，一定要給它玩一下，這兩樣我在旁邊看都覺得津津有味\
\
32\. 結訓回家（高鐵詳細版）：通常號碼越小的中隊可以越早下車，<font color="#8d2424">在車上的時候可以委託有信用卡 or 大量信金、又信得過的同分隊學友衝到售票機大量採購自由座票</font>（到高雄約 765 NTD，<font color="#8d2424">所以最好準備好數量相近的零鈔，或者跟鄰員打好關係方便週轉</font>），這樣就能最快坐到返鄉列車。坐直達車的上車以後等車開可以直接找對號座坐，查票的時候補 25 NTD（台中-高雄）就好。買自由座的好處在於不怕趕不上（以前對號錯過可以直接蓋章坐下一班，人多的時候找站務員比較麻煩，現在我不確定）\
\
33\. 可以預選分發地點的役別：警察役為首選。這梯警察的交通助跟社區巡守就很容易選到南部（儘管這梯南部人多）。<font color="#8d2424">還有一些神奇的役別會優先挑特定戶籍地，甚至有些非家因晚上可以讓你回家的隱藏役別，端看你的調查能力夠不夠強來把它們找出來。另外成功嶺幹訓班、部份役別的中央機關內勤缺會以志願的方式選填（就是不用照成績分發），有需要的人可以多加留意。</font>通常役別甄選的時候選到會讓你填資料表，其中專長欄就是專門給想要志願缺的人填的（這欄寫很多，戶籍又接近該缺額服勤地點的會被叫出來談）。\
\
34\. 收假前：記得帶制服、皮鞋跟各役別通知要帶的東西，甚至多帶幾份來做人情也不錯。<font color="#8d2424">比如消防役叫你帶雨衣，就一定要帶，不然到時候就是兩個基數</font>。另外撥交的時候規定東西要入黑袋，<font color="#8d2424">因為撥交當日程序相當冗長，常常需要扛黑袋跑來跑去，所以請先將背袋調整到適當長度，確保背起來不會痛（塑膠那一塊調整板位置要調整好，背得時候不要壓到肩扣之類的）隔天才不會出鎚</font>。\
\
35\. 撥交日：很無聊，天氣熱最好多喝點水，不然容易中暑。整隊的大隊長有的會咭咭歪歪來個收心訓話，也不管底下一堆水喝不夠、在 35 度高溫下站了半個小時的替代役男。基本上台下有一半都是體位因素來報效國家的，加上成功嶺特化感冒病毒，偶而扭一下我覺得也無可厚非，收心操這回事交給各需用機關來玩就好了，成功嶺這樣搞真的畫蛇添足。\
\
36\. 役期抵免：成功嶺可以先幫你辦役期抵免，<font color="#8d2424">不過請記得帶足抵免須要的文件：軍訓處加蓋證明章的成績單，要連大學軍訓課一起抵免就要帶高中、大學的兩張，不能說這次辦我先拿高中的辦抵免，以後再拿大學的補抵免，要辦就一次辦好。</font>\
\
37\. 役別甄選需要的文件請放內務櫃：睡我隔壁床，不喜歡穿褲子的 71號學友在甄選前一天找不到英檢成績單，打電話回家給老母要影本，老母回：『阿挖丟找謀阿，你嘎己想辦法，哇袂睏吶』。此時 71 號鄰兵心想，我一定有帶啊，於是跑去找入庫的黑袋，動員數人終於挖出那個沒名字又很神秘的黑袋，又悲劇性地找不到那張據說有上成功嶺的成績證明，後續回寢室踢倒電風扇導致風扇解體的細節就不提了。\
\
這件事告訴我們：重要的東西請隨時帶好，在成功嶺上一衰就會衰到底，不要不信邪\

38\. 心態：<font color="#8d2424">現在的成功嶺替代役新訓本質上就是加強版夏令營</font>，分、區隊長大部分都是菜鳥（拜募兵制所賜，高呼愛心服務責任紀律的褐服草履蟲變多，管理人力極度缺乏，榮譽假給的再多也沒幾個想留在成功嶺走幹訓），自己打打鬧鬧居然也不避諱讓下屬看到，口令喊錯也是常態，<font color="#8d2424">基本上只要開結訓典禮、稍數幾個場合演一下給上面的人看看爽爽就好。</font>拼到榮六的心力（天堂中隊不算）搞不好可以讓你打混超過 24 hr ，天兵不管真笨假笨永遠都過得比謹守規矩的人爽，又不像國軍可以關禁閉，只要不藏違禁品，不打架，不刻意頂撞長官人人都能爽爽玩過 15 天。真的想要貢獻社會，到專訓好好學就好。\
