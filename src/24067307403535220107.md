## <font color="#3333ff">操偶論</font>

自我加入雄中布袋戲研習社以來，社員操作戲偶的水平正逐漸下降，能獨當一面演出木偶劇的人才已不多見；身為雄中布研第五屆社長的我，曾參加籌畫多次偶劇演出，不論在操偶技巧或是幕後工作執行皆有所悟。撰寫此文的目的主要是為了提供自身的經驗給未來的社員參考，延續學長們苦心經營的傳統。\
\
\
壹 分門別類\
\
偶的操法大致可分為〝生〞和〝女偶〞兩大派系，其中生又可分為〝文生〞、〝武生〞和〝丑角〞。文生的動作可說是操偶的入門，偶的動作大多由此延伸發展，其動作的主要特色為〝輕緩中夾帶穩重〞，能做到舉手頭足皆流露出文儒的風采。武生可說是〝粗暴版〞的文生，兩相比較之下午生不僅手部動作較誇張，頭部的頓點也較剛硬，重視的是〝勁〞，時藉偶身抖動以突顯出人物的情緒。就偶行走的方式而言上下移動的可大至文生的兩倍有餘。至於丑角在動作上注重的是〝輕快活潑〞和〝豐富的動作〞。頓點不求明顯但須協和連貫，與文生的穩重恰恰相反，丑角特別需要雜亂的小動作來襯出人物的〝動〞；身體的擺動和不斷轉動改變方向的頭部操法賦予了丑角更加豐富的動作表現，給了操偶師更多發揮巧思空間。\
\
\
除去以上三種主要類別，尚有一類特殊的偶，稱做〝持扇生〞。顧名思義，此戲偶多半以左手持扇，天地同的構造異於它者，控制桿體與戲偶手腕呈一直線，故能做出轉動手腕揮動扇子動作。由於可動範圍較一般戲偶大，動作表現自然強於一般。至於另一派系的〝女偶〞也有文武丑持扇之分，與〝文生〞派系最大的不同在於基本操法大異其趣；典型的女偶使用獨特的頭部8字型操法，頓點似有若無，頭部扭動的快慢掌握幾乎主宰了整體看起來的感覺；甩袖，擦汗，以及優雅的步伐皆透露出女性獨特的韻味，熟練的操偶師更能抓住節奏，完整表達出一種深刻的魅力。\
\
\
還有一類的偶拆下天地同或者連旁肢一並拆除，由操偶師將手伸入戲偶袖中直接操縱戲偶手腕。這種操法主要是用來加強戲偶的手部動作表現，也能用來豐富持刀劍等兵器的戲偶的動作。總歸而言，偶的神態可由其動作完整呈現、表達。戲偶是死的，人的動作是活的。是操偶師父賦予了戲偶生命，戲偶也能看作是操偶師的分身；當觀眾能從偶中看出熱情，那麼身為操偶師的你就成功了。<br />

## <font color="#3333ff">第一屆南區操偶研習營記趣 &nbsp; &nbsp;</font><span style="color: rgb(0, 0, 0); font-family: &#x27;Times New Roman&#x27;; font-size: x-large; line-height: normal; background-color: rgb(234, 236, 244)">March 26, 2005</span>

在5月9日這一天，霹靂布袋戲在高雄舉辦了第一次南區操偶研習營。身為此活動協辦社團─雄中布研社─的社長，我跟其他社員們在活動開始的前一、兩個小時就開始著手佈置場地以及其他雜事。而在這一番手忙腳亂之後，霹靂的人員帶著上課的教材還有──一大堆的戲偶出現了！&nbsp;\
\
\
不過片刻，大部分的學員到齊了。首先，由霹靂方面的人作簡單的自我介紹，為之後一連串有趣的課程作開頭。今天教我們操偶的是林奎協老師〈四無堯〉，他幽默的談吐使我們不再陌生，在課堂上不時充斥著笑聲，增添了不少活潑氣氛。接著便是各個社團的自我介紹。我們雄中布研社打著『地主隊』的名號，在所有學員中足足佔了四分之一，果真名副其實啊！不過是否會有搶眼的表現，這還不一定〈呵呵，看到後面你就知道了！〉經過一番折騰，千呼萬喚史出來的操偶研習營終於正式開始啦！&nbsp;\
\
一開始四無堯老師先為我們講解有關戲偶的分類、構造、以及演變。他用了豐富的肢體語言和詼諧的言詞將有點嚴肅的課程變的十分生動，讓學員們一反平時上課的態度，津津有味地聽著，吸收上課的精華。不知不覺已經到了中午，趁著空檔大家結伴去用餐，並且休息片刻為下午的實際演練儲備體力。&nbsp;\
\
哈哈哈，在期待許久之後，終於可以把偶拿起來玩了，心理頓時十分痛快！親切的四無堯由最基本，但也最不容易的走路開始教。這個動作難在掌握它的協調性。在我們拿起偶練習的同時，四無堯和其他兩位操偶師也一邊指導每個學員，糾正我們的動作。在這之後，四無堯用它精湛的操偶技巧示範生、旦、淨、末、丑等等不同角色的一些常見動作。以小旦為例，頭部的扭動加上手部擺動，害羞的動作，這些即是主要的動作。不過之中還隱藏許多的變化，要將女偶嬌媚的神態完整表現，果然只有經驗豐富的操偶師才能做到吧！&nbsp;\
\
在整個活動結束前，為了驗收今天的成果，每個社團都要上台表演，每個上台表演的人都使出渾身解數以求有好的表現。有人拿著18吋的銀狐表演賣膏藥，在場的人都笑翻了！最後的壓軸當然是我們雄中布研社啦！學長有模有樣的操偶加上眾多學弟合演的一場鬧劇，使我們博得許多掌聲。最後每個表演者都得到鼓勵─霹靂2004年的桌曆，而我們雄中則得到了……正版九皇座VCD一套，這份大獎真是令人驚異啊！我也開始期待明年第二次的操偶研習營了。總之，這次活動辦的非常成功，而令人有不虛此行的感覺。我也學到了不少的操偶技巧，整個活動就在非常歡樂的氣氛下結束了。<br />
