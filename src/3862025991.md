[PENSEES](http://en.wikipedia.org/wiki/Pens%C3%A9es)&nbsp;暝想錄&nbsp;&nbsp;152&nbsp;\
Prides --- Curiosity is only vanity. Most frequently we wish to know&nbsp;but to talk. Otherwise we would not take a sea voyage in order never&nbsp;to talk of it, and for the sole pleasure of seeing without hope ofevery communicating it.&nbsp; &nbsp;Blaise Pascal ,in PENSEES\
\
傲慢\
\
好奇心不過是愛慕虛榮罷了。大多數的情況，人們求知只是為了炫耀，你總不會特地出海旅行卻從不跟人提起這回事吧？單單為了自身一人的樂趣去作這些事，壓根兒就不希望跟其他人訴說自己的豐功偉業？\
\
\
寫 PENSEES (暝想錄) 的 Pascal 就是我們很熟悉的那位 Pascal ，雖然暝想錄的內容大多是為了宗教論證而作，卻兼具哲學與文學之美，算是相當有趣的作品，消遣讀讀也無妨。上面中譯我稍微修改過了，為了通順，文意可能有所偏差，參考參考就好<br />

解析度以外增加A4大抄資訊含量的新方法\
\
\
\
\
根據我跟揚智的詳細討論，開發出數種非光學式，兼具創意及實用性的高密度及高容量 A4 大抄製作法 XD\
\
\
方法一: 圖層堆疊法\
\
由揚智提出，利用市售可擦式原子筆套寫在第一層縮印字跡上，比方說第一層基本公式與第二章的內容，可擦式字跡寫第一章的內容，作答時寫完第一章的題目再擦掉全部字跡，繼續用第一層的公式寫第二章的題目。如此一來，可記錄的內容瞬間增加一倍，足足提升了 3 dB !可惜這個方法無法大量複製，損失造福大眾的可能性\
\
\
於是本人又開發一種簡單作法來獲得這夢幻的 3 dB v(￣︶￣)y\
\
\
方法二: Mobius bug 法\
\
將 A4 paper 裁接成長紙環，接成 Mobius 環，根據規定考試可以攜帶一張&nbsp;A4 ， 若教授允許一張 A4 可以被定義成兩面 A4，那我們就可以做兩個 Mobius 大抄進考場了，在不犧牲解析度的前提下利用純幾何方法獲得3 dB gain\
\
\
可惜此法有一個很大的 BUG如果監考的助教拿一把剪刀從你的紙環的正中央順勢切一圈你精心作出來鑽漏洞的 Mobius 大抄就退化成普通的紙環了 \<囧>\
以上方法徵求勇者進行實戰測試 XD\
\
\
事實上，在不規定 A4 paper 厚度下還是有很多正規方法可以增加單位大抄面積的資訊量，比方說盲人點字法(可是必須先學點字)，全像術 (必須外加光源)，數位化搭配 1500 dpi 高解析印刷技術 (可說是最具前瞻性與發展潛力的傳統手段)\
\
\
根據大抄界的摩爾定律，每隔數年大抄的資訊量可以有倍數般的增長其極限應可達到人眼辨識的極致，最終的瓶頸應在於有沒有熱心又無聊的人士肯花費時間製作可查性高的究極版大抄並加以改良。\

<font color="#3333ff">&nbsp;論簡體書</font>&nbsp; &nbsp; &nbsp; &nbsp;\
\
寒暑假回高雄的時候，三不五時就會繞到文化中心附近的若水堂（可能是本店吧）翻翻書，不為什麼，就因為那裡有免費的咖啡還有舒服的座位可以賴著看書！不是很寒酸的即溶咖啡喔，是滿滿兩大壺擱在保溫裝置上煮好的 研磨咖啡 喔\
\
\
常常喜歡窩在那，看一些數學類的書，捧著熱騰騰的咖啡過完悠閒地午後時光以避酷暑\

\
\
沒想到若水堂在台北也有分店了，今天下午特地去探探免費的咖啡是否仍在，不出所料，靠近落地窗的一塊區域被劃做閱覽區。兩個黑軟皮沙發，一個透明茶几，再配上一杯熱騰騰的咖啡，還能愜意地欣賞窗外美景，實在是個打發時間的好地方呀\

\

\
\

甚至還有原版授權的廣辭苑哩 （可惜日語程度還不到家，不然真想買一本當枕頭睡...）。除了豐富的英日文學習資料以外，還有很多俄文法文德文西班牙文的學習書籍，好像還有希伯來文，阿拉伯文等等很炫的參考資訊\

<font color="#3333ff">&nbsp;Vacuum Tube Buffer （</font>12AT7 5965 ECC81 套件）&nbsp;\
\
通電以後真的可以 work 呢！第一次完成這種元件數比較多的板子，超有有成就感的 v(￣︶￣)y(可能有一兩百個焊點，而且正反面通通都得焊過一遍)\
\
原理：簡單來說，這個真空管 buffer 差不多就是一個實體的類比 filter。它的作用其實也很簡單：加一點奇特的噪音到原來的聲音訊號中。這就神奇了，既然加了 buffer 會讓原來的聲音失真更嚴重，為什麼還是有人喜歡用類比線路呢？單就音樂性來看，一般 cd 的數位信號在母片錄製的時候都經過專業的混音師調整過，目的是要讓量產的 cd 送到不同的機器上都能呈現出一定水準的聲音。有些花大錢搞音響系統的人會開始追求原音重現的終極目標，比方說更高的取樣頻率啊，更純淨的訊號源之類的。\
\
不過修過信號系統的各位應該都知道，當你錄音取樣的時候其實就已經經過一次轉換，不管你再努力設計多聲道喇叭系統來重建聲場，最好的狀況也不過是達到當初錄音用的麥克風的取樣水準；另一方面，每個人耳朵的形狀都不一樣，對不同頻率聲波的敏感程度也不同，再考慮錄音現場的氣流擾動，原音重現的逼近程度就跟測不准原理一樣，存在某個不可逾越的極限。（就算架個麥克風陣列，透過干涉繞射推出正確的邊界條件，要計算各種諧波在密閉的錄音室裡來回傳遞後回到人耳的最終效應還是一件很麻煩的事）\
\
\
\
所以說，對於像我這種不在乎原音重現，耳朵解析度又很差的人就會想辦法用各種手段調整音響的音色讓自己聽起來爽一點。一般的數位音源聽起來太乾淨，怎麼說呢，有的時候會讓有聽起來很假的感覺。這當然跟當初後製專輯的混音師有關，功力深淺全反應在消費者耳裡。若透過以真空管為主的 BUFFER 加入一點中低頻的 distortion ，有的時候會給聽者帶來一種溫暖的感覺，甚至可以加重音樂中人聲的特殊音色，增添幾分韻味。\
\
\
實測結果：吉他類型的音色跟抖喉嚨的聲音有明顯強化，應該說這頻段諧音跟真空管雜訊很 match，聽起來稍微過癮些。像是桑田大叔的歌聽起來更有味道些，演歌類型的樂曲也有旋律加強的感覺 （不過有些本身錄音時已經調過的，反而會有糢糊化的反效果）；Sarah 的歌倒是明顯柔化，高音聽起來比較不哪麼刺耳，耳朵的負擔減輕很多 ^^。不過這個 buffer 就不太適合拿來放無人聲的音樂了，以純鋼琴演奏而言，某個頻段的音很明顯可以聽出缺陷，很容易讓聲音糊在一塊；有些歌手的聲音太過純淨，其實也不適合搭配 buffer 用 （比方說夏川里美的嗓音），總體而言像南方之星這類，帶點輕搖滾的樂曲呈現出來的效果最令人滿意。\
\
\
\
結論：加入 buffer 額外提昇的爽度： 3％ &nbsp; （1.5％ 是心理作用 (￣▽￣＃)﹏﹏）再用加上 MD 作為數位訊源應該就很完美了，sony MD 裡的那塊 DAC 可是相當優秀啊。光看 buffer 裡真空管紅通通的燈絲感覺就超棒的，音質有沒有提昇倒是其次，拿來炫耀唬人絕對夠用 （我就不相信大家耳朵都那麼好，256 kps 的 mp3 檔案只有 wav 的四分之一，不仔細聽我還分不太出來了.... ），譁眾取寵的最佳利器 ( ￣ c￣)y▂ξ\

<font color="#3333ff">獻給自己</font>\

高一的時候，在同樣日子買了好大一盒剛普拉來犒賞自己。那還是狂迷 Katoki 機械設定的時代（到現在仍是），始終不明白為何當時有體力有耐心，僅僅用了一天的時間就把五六百個塑膠零件處理得乾淨俐落，連勾出輪廓的墨線也硬睜著眼仔細描擦。之後就再也做不出比這更棒的作品了，書架上，八月裡完成的大比例普拉模變成最耀眼的存在。\

<font color="#3333ff">字</font>\
\
最近想做個有趣的小實驗，想研究看看是否能從一個人寫的字看出他的個性或者揮毫當下的情緒來。所以囉，就拿自己為範本，有空的時候就抄抄書，多作些樣本以供試驗。\
\
放鬆心神，全神貫注在筆尖上，挑動腕臂勾勒出一個個型態各異的行草。有時用粗壯的圓筆尖用力地在便條上刻下一句句感情強烈的歌詞，以洩盡一天的勞累，而石刻般的蒼勁留下湛藍的軌跡，略顯豪放。更多的時候，我喜歡試驗鋼筆 K 金尖的柔韌，尚不能完全掌握那細頭銥點的巧妙觸感，一闋詞、抑或是一首新詩，寫來總帶點潦弱的氣息，氣若游絲地在光滑的紙片溜過，稍一加力，瀉出的墨量又不依我恣意佈弄，最後爬繞在頁上的詩句總與預想的有所出處，相當調皮，卻也十分有趣。\
\
幾天練字下來，也愛上這凝神寧心的活動，起始目的反倒不那麼重要了。品茗危坐，放空心思，一邊抄錄著書上頗勘玩味的字句，一邊細細咀嚼著箇中滋味，神趣漾然，倒有幾分閒情在。\
\
以習字帖為日記，好處是不受拘束，想寫什麼就隨心揮灑，不論留下何種內容，豐富的情感依舊萌發於龍飛鳳舞的行句之間，也紀錄了當下的心境。長期利用電腦來寫作文章，有些字的形貌寫來真有些模糊，或許這也是對一個美麗而古老的語言保持熟悉感的好方法吧\
\
我很少寫筆記，一則懶矣，一則寫了也沒多大的機會再瞥上那麼一眼，所以我也不是一個喜歡寫字的好學生。小的時候學過一點硬筆字，即便寫快得時候潦草些，若沉住氣來，腦中縈繞著字構筆順一步一步排佈每個勾勒、點、撇、曳，還能勉強寫出一手堪看的字。近來總想把鋼筆字鍊的柔暢狂美些，一直很享受那種滑過紙上的舒暢感，玲瓏有致的行草只有用鋼筆尖才能輕易耕上雪白的頁。\
\
只恨學不精，總難完整發揮出那桿視若珍寶、白金牌 3776 的全副實力，白白糟踏了一隻好筆。希望寫乾幾瓶老墨以後能有所斬獲，別總是讓筆下的文字跟不上美麗的思想。\

<font color="#3333ff">千年女優</font>\

女優，在日文裡的意思就是女演員。橫跨千年的劇中演繹，戲裡戲外不斷地追尋那個留下鑰匙的初戀男子，故事裡的千代子耗了大半生仍是原地踏步，刻在心版上那抹朝暮思念的臉龐，早已模糊地和入悲傷之中。留下來的，只有一把黃澄澄的鑰匙，飛快奔馳的腳步，在追尋的過程之中找尋自我的千代子。\

這部千年女優已經是好幾年前的動畫片，大概跟神隱少女同時期吧。早上到圖書館的時候一口氣看完了這部頗受好評的傑作。果然，光從它的 BGM 就可嗅出一絲不凡的風格，雖是幾年前的片子，作畫的精緻度也沒啥好挑剔的，特別的運鏡和畫面雜湊更是凸顯出動畫的優勢，營造出一種一般真人電影不容易製造出來的夢幻感，形成一種錯落有緻的緊實感。\
\
就劇情來講，確實吊足了觀眾的胃口，巧妙地運用演戲的場景穿插回顧千代子不斷追尋的一生。除了千代子純純的愛以外，一直默默喜歡著千代子的鬍子先生也有趣得很，他的愛不是佔有，比較像是一種無回報的付出，難道這也是初戀帶來的那股酸澀甜美的滋味？（XD ，我好羨慕啊）\
\
最讓我產生共鳴的一點，應該是千代子那股不斷追尋目標的衝勁。儘管到了後來，千代子再也回想不起日夜思慕的那個臉龐，在尋找鑰匙主人的過程中，她似乎也開始享受扮演這樣的自己，大概這就是過程重於結果的一個好例證吧？想想自己，全新投入研究某些事物時，也會產生一股異樣的執著；在旁人的眼裡，這樣不理智的無謂堅持可說是近乎愚蠢，猶如無法脫離幼年幻想的稚氣。這樣的自己，一方面體認到這缺乏理性的行為，卻又忍不住投入全副心神在這近乎瘋狂的的任務上，豪賭一把。事實上，在追尋目標的同時差不多就獲得了等值的滿足，是否達成一開始所計畫的結果，已經不是那麼重要。有的時候，反倒是這股執著造就了最重要的東西。\

墜落到底的同時，整個人也清醒了過來，最有趣的便是身體極真實的反饋動作：我夢過高速向前奔馳的狀況，醒來的時候往前揮動的右臂將桌上得礦泉水瓶打飛； 我也夢過我從高不可測的跳水台魚躍而下，醒來時我的四肢也做出劇烈的反應 ------ 好像我真的摔過一樣。\
\
這段休憩的過程頂多十幾分鐘，真正意識到開始墜落到終止之間我『覺得』僅過了幾秒中而已。一開始可能只有緩慢穩定漂移感，一旦意識到自己正在『移動』後卻會開始加速，在模擬碰撞地面的時候恰恰醒來，夢境乍然而逝，留下的只有劇烈起伏的胸膛以及緊緊繃起的身軀。\
\
這種夢感覺很怪，醒來以後精神卻變得相當好，也屬於容易上癮的那種。\
\
跟鬼壓床比起來，這種反倒像是過份敏感地操縱身體，藉由極度放鬆的方式累積獲取一瞬間的釋放。以前在 Discovery 有看到節目介紹一種類似於這類狀況的禪坐，藉由冥想，放空思緒，經過一段時間後似乎也能達到使肌肉瞬間緊繃的效果，讓盤坐的雙腿忽地夾個角度，人就從草蓆上『彈』了起來，好像還可以跟打水漂兒一樣玩連續動作呢！\
\
還有一種特殊案例，也就是『分段做夢』的情形。我想，這只有愛賴床愛睡回籠覺的人比較容易體會。有些鬧鐘不是有貪睡鬧鈴的設計麼，我曾經間段地、十幾分鐘一次連按了兩個小時。我按掉鬧鈴的當下多半是確實清醒地聽到鬧鈴聲（nokia 的單頻鈴聲相當清楚），可卻能在按除鈴音後馬上進入夢鄉，並有很大的機會可以連續之前未完的夢。\
\
我大概可以連著編上四、五個獨立分割、情節連續的『夢』。\
\
我有過最奇怪的『組合夢』，大概是受到『寒蟬鳴泣時』這部推理式同人創作的影響，竟然有『本篇』跟『解篇』的形式並立存在！\
\
你能想像嗎？兩個獨立的夢，竟出現完全相同的人物，以不同的場景敘述著同樣的情節。就感覺上，我在做第二個夢的同時也有逐步編輯的感覺，甚至是一絲絲恍然大悟的痛快！\
\
撇開夢的內容不談，我認為『分段做夢』之間清醒的狀態跟『鬼壓床』的態勢有幾分相似：很容易就陷入睡眠的階段，如果能適時清醒過來則後續完全不同，這就是賴床不賴床的最大區別。\
\
\
我常在想，賴床是否有辦法靠意志力去克服，或者單單是種無法事後解除的睡眠障礙？如果鬼壓床能靠意志力解除，那麼我相信賴床的問題也能用同樣的方式去改善。 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;&nbsp;\

<font color="#3333ff">錯覺</font>\
\
昨晚離開研究室的時候，一時想不起來那把綠色小傘究竟被我扔到哪去。左思右盼之餘，總感覺不大對勁，進門前的確還不斷地把弄著那玩意，怎一眨眼就消失地無影無蹤？我只得無奈的走下樓，緩步走向車棚，心裡不斷思索著我先前的行程，試著推演出折傘離開我身旁的確切時間。腦海中鮮明的記憶告訴我：打開研究室的大門前，手上確實還有傘，一定是隨手放到桌上的某個角落去了。\
\
自顧自地走到愛車旁，正想著要不要折回去拿傘時，卻發現思思慕慕的它正安靜地躺在車籃之中。\
\
好呀，我居然被偽造的記憶給矇騙了。仔細想想，這樣的經驗也不只發生過一次；有的時候總覺得某樣東西看來十分面熟，或者錯認堅信某樣事實而不自知，總信誓旦旦地宣示自己沒記錯，直到查了書以後才驚覺自己出了個大糗。\
\
有些幾近全聾的老人總時常聽到某些年輕時熟悉、愛聽的旋律，似不停歇的樂曲總要自己大聲嚷嚷才能遏制。腦神經學家認為這是一種大腦的補償作用，長期與外界音源隔絕的半聾人，腦部會試著模擬一些音源滿足自己，算是蠻普遍的病症，或者說是上天的恩賜吧。\
\
頻死經驗也是科學家正在研究的一個有趣現象，據說有許多從死亡邊緣拉回現實的人都曾發生過，他們也許是看到某道特殊的光芒，看到自己信奉的神蹟出現，又或者是靈魂離體的奇異感。這些奇特的經驗如果沒經歷過可能很難理解，有部份的科學家認為這種經驗可以從大腦萌生的錯覺去解釋，能否證實，尚未定論。我自己是很同意這種看法啦，搞不好哪天人類就能製造出以刺激腦神經為基礎的虛擬實境機器，人人都有機會探訪那獨特、與現實截然不同的虛幻之境。\
\
\
傘找到了，我的心仍舊沉醉在腦袋威能帶來的震撼，越發興味，不能自拔。\

<font color="#3333ff">〝月讀〞，座落在鬧市裡的一個小天地</font>\
\
\
〝月讀〞是間典雅精緻的小咖啡廳，也是許多人心中的夢幻之地。它位於喧鬧的建國路旁一條平靜的小街裡，不大明顯的招牌讓人不易發覺它的存在。雖然店舖開張的時間還不長，卻已經吸引了許多客源；不為什麼，只因它是少有的〝女僕咖啡廳〞。可別想歪，這跟別的咖啡廳沒多大的出入，只不過店內的女服務生身上穿的是特別的制服：一襲黑色連身加上白色花邊點綴的短裙，配上延伸至膝蓋上方的黑色長筒襪。或許這也算的上一種視覺上的饗宴吧！店內數坪大的空間只擺的下六組樸美的木製餐桌，正對著店門的廊道區隔開了左右各三組桌椅的用餐區，直直通入烹煮美味佳餚的小廚房，同時也是是一個有著靈巧設計的吧台。從背對門口的座位往屋內望去，能清楚的看到在平底鍋前眼神專注的女侍，坐在收銀台前撥弄著窗簾流蘇，穿著可愛女僕裝的櫃檯人員。炎夏的熱浪絲毫影響不了屋內寧靜典雅的氣氛，與屋外截然不同的奇異世界讓人迷離，使人萬般陶醉。\
\
\
趁著期末考結束，小巴、泰禹、家昌還有我跑來月讀喝下午茶。最初我們抱持的是一種好奇嚐鮮的心態，畢竟這類型的地方從未去過，總想試試看它的威力。甫入店門，就聽到站在木門兩旁微微行禮的女侍對我們表達歡迎的言詞，可惜一連串的日語問候語讓我完全不知句意，但從她們臉上的微笑即能探知一二。接著，更有殺傷力的對話出現了──沒錯，這些女僕們稱呼我們這些客人為〝主人〞，這種待客之道可真是令人受寵若驚，對我們這些第一次光臨的客人而言還真有點難以招架。光是聽到一開始招呼的言詞：〝請問是四位主人嗎？〞總會不由自主地起雞皮疙瘩……(雖然心裡暗爽……)。\
\
\
若是你認為這不過是一個賣弄姿色的取悅客人的場所那就大錯特錯了！在這裡女僕們一旦端出餐點給客人時，口裡除了禮貌地詢問：〝請問這道菜是哪位主人的？〞(雖然是容易讓人起雞皮疙瘩的話語)，臨走前還會對著點這道餐點的〝主人〞行禮並緩緩退開；最令我欣賞的是她們臉上一直都掛著一抹微笑，讓人心情看了跟著愉快起來。多虧今天不是例假日，店內只有寥寥數人，少了人群的吵雜，多了幾分靜謐和諧之感。看著女侍緩步行走在廊道上優雅的姿態，略為彎曲的唇瓣勾起臉上迷人的酒窩，落在那雖稱不上絕美卻清雅動人的粉頰上，似乎有種難以描述的滿足沁上心頭。只存於二次元的美不知為何竟出現在真實的世界裡。我喜歡那種協調感，美麗的微笑帶來的莫大的衝擊；我不是那種會對特殊cos服抱持奇異幻想的人，但還是抵擋不住這種美。廳裡放著柔和的音樂，聲優美麗的嗓音演繹出的動人樂聲讓人沉醉；等待餐點時翻翻店內提供的日文書冊，與同桌好友閒聊，這是一個讓人徹底放鬆身心的好地方。\

<font color="#3333ff">依然故我</font>\
\
昨天小巴跟我兩個人帶著滿腹熱血在建國路上找尋目標。兩個小時過了，懾服於令人訝異的3D畫面，手裡多了幾款illusion公司的遊戲，幾個一時興起買下的盒玩。打開包裝，不由自主地咒罵起小八的烏鴉嘴，或者根本是自己的運氣早在甄試時用光，哀怨地拿到最不想要的〝地雷〞。這或許就是扭蛋真正的樂趣啊，一切都交由命運來決定，用不著浪費猶豫的時間。\
\
時光彷彿重回到高一、高二的時間帶，店家沒變，街上的景色依舊如故，只是逛街的人不再屬於那個輕狂的時代，卻仍就做著不是一般人該做的事。高中三年轉眼間就過了，我也發覺自己真的變了很多；改變的不只是自己的思考方式，更多的是與日俱增，別人眼裡的不良習慣。說來也真是奇怪，為何我身邊的好友都是些奇奇怪怪的人，有蘿莉控，有一堆淫蟲，或許還有宅男吧；搞的我都被同化成半個御宅族了。原來雄中就是這樣啊。小巴就是罪魁禍首，讓我一頭哉進動漫這塊領域，還把我拉進建國路這個動漫精品同人誌的集散地，從此踏入了一條不歸路。或許是互相影響，說不定是我骨子裡就有就存有這類奇怪的基因，只是上了高中後被徹底引發，受到身旁眾多同好而產生共鳴，敗家的血脈就此成長茁壯。再加上父母從來不約束我的興趣，只要我成績保持一定即可，我的行為自然更加肆無忌憚，瘋狂地去滿足自己易於常人的物慾。如今，擺在房間裡的漫畫小說早就超過了兩百本，架子上放滿了自己花長時間作好的鋼彈模型，抽屜裡早已被一堆乖小孩碰不得的東西給填滿；一本本原文的畫冊、設定集都是我省下餐錢，甚至是賣力打工換來的。\
\
有時想著自己在建國路的消費早已超過兩三萬，不免暗自吃驚，難道自己真的是個無可救藥的御宅族？買到心裡期待已久的新模型，在班上和同學討論著最近看過的動畫劇情，甚至爭辯著某某漫畫家的畫風是如何的吸引讀者，如此種種都會讓我感到十分愉快，一種莫名的喜悅湧上心頭。這大概是一種紓解壓力的方式吧！我倒是不在乎別人怎麼看我，我只是表現出異於常人的興趣，喜歡跟擁有相同喜好的人分享由此得到的喜悅而已。誰說看漫畫對學習一定有害？泰禹跟我還不是一樣考上台大電機，課餘興趣並不是學業的障礙呀！\
\
看來自己早已臣服於來自日本的次文化，或許自己也早成了一個不折不扣的變態，現在的我買包裝上有個紅色小圈圈的商品時臉上的表情是一貫的駕輕就熟，壓根兒都忘了自己還是個未成年的小弟弟呢。慾望需要發洩，人跟野獸最大的差別在於〝克制〞兩字，控制得宜就能活的快樂。\
\
這篇文章不知道算不算是我的新御宅族宣言？我一點也不喜歡自己一個人悶在家裡看著二次元的貓耳少女發呆傻笑，孤獨地盯著電視上閃過的景象，將欣喜深深埋於心中。小的時候母親從來不買我想要的玩具給我，我只有一本本早已看過好幾遍的書。我只能用我的想像力，幻想出一幕幕自行建構的世界，想辦法由此獲得更多的樂趣。長大了，一直想補足童年時那模糊，從指縫中溜走的渺渺缺憾，我也意外地成功找到那一直渴望的小小幸福。\
