格檔率說明:\
\
天賦樹主結構其實用野蠻人, 貴族跟決鬥者都可以用同樣的配置, 以前玩 D3 走站樁野蠻人, 天賦盤沒看當然先選 Marauder, 練到中期拿到亂世之翼想 build 才果斷換成貴族妹子起手,&nbsp;<font color="#a82e2e">只有貴族起始可以簡單取得額外的 6% 雙持物理格檔(2% \*3)</font>, 使用亂世之翼的基礎物格為 15%+裝備詞綴 10%=25%, 天賦樹中雙刃之力那圈提供 8% 物格, 右下角劍刃屏障則提供 11%物格, 霸體隔壁的修行之刃則是 6% (還有一點 2% 可點) , <font color="#a82e2e">天賦樹</font><font color="#a82e2e">總合為 25% 物格</font>, 若由<font color="#a82e2e">貴族起手很容易多投資四個天賦點達到總合 58% 的物理格檔</font>, 這個時候若配合裸奔頭([祭禮之雨](http://poedb.tw/unique.php?n=The+Bringer+of+Rain)) +15% 物格可以很容易逼進 75% 的格檔上限, 若再加上法格鞋可以達成雙格檔皆滿的狀態&nbsp;\
\
不過搭配裸奔頭的狀態並不利於熔岩之擊的輸出最大化(近戰傷害不會加成到投射物, 最多4L), 另一項可以增加物理格檔的非武器裝備則是 +10% 物格的信念之砧(The Anvil), 但是機會成本太大(不能用拉茲瓦又扣攻速), <font color="#5040ae">想用WoE配合熔岩之擊無腦尻並唯達成物法滿格檔的方式就是透過魯米靈藥</font>(湊巧在世界頻看到有人打到, 果斷用近頂打寶水 +10c 換到, 洗了兩次就有 +40%/+19%, 一用之下驚為天人); 天賦樹不需要點滿物格,&nbsp;魯米靈藥喝下去一定湊滿 75% 物理格檔, 此時搭核心裝轉換得到的法術格檔有 75%\*75%=56%, <font color="#5040ae">只要你的魯米水法格屬性有 +19% up 基本上就直達上限</font>, 20%品質可以得到額外 0.8秒的持續時間, 換言之<font color="#5040ae">總共可以維持約 9 秒的滿格檔狀態</font> (喝兩次, 每次 4+0.8=4.8秒), 配合受傷施放不朽戰吼的物理免疫, 有 3000 血在很多場合都可以站著尻熔岩之擊(好懷念 D3 的先祖錘, 玩起來有像), 每秒 4下 12 顆球的擊中回復生命搭藥水基本上沒有吸不回來的場\

熔岩之擊相關天賦:\
\
祭血術(血魔法效果), 零點射擊(近距離 50%投射物傷害加成), 堅鐵之力(力量加成至投射物) 列為主要點, <font color="#5040ae">招式</font>連線<font color="#5040ae">洞數每多一個傷害級距差不多就是 40%</font>, 熔岩之擊配合亂世之翼如果沒有五連以上打人大概像在抓癢, 用祭血術除了解決缺魔問題以外就是空出一格放增傷輔助技能石, 加上零點射擊與堅鐵之力就是帳面上看不到的 DPS 增幅效果 (合起來至少 200% up 的倍率 ) &nbsp;\
\
另外若熔岩之擊若配低/高階多重投射可以試著點瓦爾冥約(回)\
\
基礎能力要求:\
\
天生基礎智慧搭拉茲瓦給的 20\~30 智就足夠放脆弱和易燃詛咒(往堅鐵之力的主幹道進決鬥者區的支道可以選 +10智或 +20力\*2), lv20 的快速攻擊需要的 109 敏用貴族或決鬥者起手天賦樹吃到零點射擊與強化之膚那圈血量會剛好, 不走強化之膚(吃必中附近那圈的蠻化)就點 +30敏的大點(捷影).&nbsp;\
\
霸體與烈士意志:\
\
這組天賦算是綁定組合, 要嘛都選要嘛不選. 最大優點在於免暈以及裝備選擇的彈性(可以選力敏甲). 閃避基本上與格檔算是同類型的減傷, 要嘛 0 傷害要嘛傷害全吃, <font color="#5040ae">在血量有限的情況下面對高瞬傷生存能力主要還是看單算血量與護甲或抗性帶來的等效血量, 減傷機制(受傷施放, 護甲水)能不能把血線拉滿就要靠不間斷的擊中回復, 所以免暈很重要.</font> 不過一旦其它裝備帶來的生存能力足夠時, 這組天賦其實可以不用點, 反正只要兩顆後悔石就可以換著試.\
\
必中天賦:\
\
照我的天賦走法要上<font color="#5040ae">堅毅之心的成本是 7 個 +10力量點,</font> 同樣的點數不走必中可以走夜之狩獵圈(ˇ3點, 14全抗, 36%命中) 與俊敏(2點, 30%命中), 戒指的一個抗性詞綴換成 +命中. <font color="#5040ae">有易燃詛咒不用擔心無爆擊的點燃問題</font>, 大概等級越高的時候前者越強, 哪種走法好還在試.\
\
充能球:\
\
耐力球與狂怒球對於這個 build 而言前者可以提供不錯的物理減傷(對於未喝護甲水的狀態有幫助)與延長不朽戰吼的效果, 後者配鮮血狂怒技能有 4%攻速增益. <font color="#5040ae">狂怒球不值得點</font>, 天賦樹上有更多攻擊類天賦可以提供大於 4%攻速增益, <font color="#5040ae">有主動吼球習慣的耐力球可以考慮點 1\~2顆出來</font>(天賦盤一顆, 到賊獎勵一顆),&nbsp;\
\
\
光環類技能:\
\
用了祭血術再放任何光環類的技能都會大幅削減等效血量, 就算配致死定罪跟白狼頭都一樣, 天賦樹左上角的主權(3點 ,魔力保留 14%) 吃不到也不值得這個 build 投資.&nbsp;\
\
\
有家底貴族天賦樹走法(約 15hr 到 lv60 成型):\
\
走哨兵<font color="#5040ae">直衝祭血術(15點)</font>, 接著<font color="#5040ae">吃完貴族隔壁的血量大圈</font>以後換6L白袍尻熔岩之擊,等級夠了輔助技能石一顆顆接著放上去(零點射擊算是過渡期會放的), 接著直衝零點射擊, 有障礙就先吃無血之體那圈血量. 接下來血量夠大概可以扣個 10來點先不點, 攻擊面因為有 6L 熔岩之擊所以光升級輔助寶石跟換孩子王傳奇武就可以保持碾壓感, <font color="#5040ae">接著走上方戰鬥精力的護甲與血圈, 決鬥宗師的護甲圈或魔像血統的血圈</font>, 打算一路雙持到 lv60 可以接著把劍刃屏障大圈走完(不過不建議, 進無情前有很多傳奇雙手武可以玩, 比如說瑞佛的奮戰長劍, 配到 50%跑速玩起來九成像配了九頭蛇的易大師, 跑圖好玩). 1保持比圖少 5\~6級的速度<span style="line-height: 0; display: none">﻿</span><font color="#5040ae">上無情以後透過戒指與其他防具把抗性補滿</font><span style="line-height: 0; display: none">﻿</span>就可以在薩恩廢墟刷到<font color="#5040ae"> lv60 換成亂世之翼與法格護身符</font>, 一路解任務到神主 ,一邊<font color="#5040ae">把格檔大點與剩下的血量補齊</font>, 無盡白衣可以換成正常的 5L 血抗衣, 接著就進入 end game 刷圖打裝流程\
\
\
Build 成本與裝備走向:\
\
不算寶石, 主武器不到 10c 就有, 用神聖大概洗到 105% 以上算堪用, 項鍊自己就打到兩條, 市價大概也不到 5c 吧, 光是為了調整天賦樹重練一隻貴族上 lv60 以前撿的 c 就有 7\~8 顆 (第一支白手起家野蠻人打玩無情神主還沒看過半顆, 有夠扯), 重練的過程大概就可以湊到核心裝等值的通貨. 戒指跟腰帶在能刷黑石或圖書館湊裝賣以後就是無腦點金, 不同類型的100+抗戒可以存一堆看心情換, <font color="#5040ae">大致將混沌抗稱到 0%, 三抗全滿就與頂法格相得益彰</font>. 裝備的手套, 鞋, 與頭盔都還有預留攻擊屬性的空間(目前用富貴手, +30% 跑鞋, 雷諾姆豪情火傷 50% 避凍頭), 在裝備血抗足夠以後天賦樹還有走傷害圈的餘裕,&nbsp;不過<font color="#5040ae">最大輸出已經被亂世之翼限制住了</font>\
\
假如有能力拿兩把高傷害單手武或 6L雙手武, 配合法格鞋基本上也會有一樣的雙滿格檔效果, 不過就不是 WoE build 了\
\
\
再來就是魯米靈藥這個關鍵裝備, 個人認為這瓶藥水對於雙持格檔來說效果逆天, 幾乎少綁定兩個裝備就能達到物法滿格檔, 要是能弄到兩瓶以上大概無腦站樁不是問題(完全把瓶頸丟給 DPS), 歸根究柢 POE 的格檔幾乎等效閃避, 一格檔就是零傷害, <font color="#a82e2e" style="font-size: 13px; line-height: 1.5; background-color: initial;">像魯米靈藥這種直接補護甲(增加格檔失敗後全吃傷害的等效血量, 還吃天賦樹護甲%數加成)又加格檔率的道具絕對是不合理的存在.</font>\
\
特殊道具搭配:&nbsp;\
\
<font color="#5040ae">虛空慧眼(+5 寶石技能等級)配 lv20 熔岩護盾</font>:法格沒撐滿前玩過, 有很高機率被火燄脆弱的大群小怪反傷打死, lv25的熔岩盾可以吸 4700+ 傷害, 大概可以比 lv20 多吸收 2000+ 的傷害, 相當有潛力的等效血量稱法, 唯一的風險就是反傷, 再來就是要拔掉第二層受傷施放的護盾避免盾被洗掉\
\
<font color="#5040ae">斯塔空加之首(瀕血 50% 減傷):</font> 還沒弄來玩過, 不過可以預期這個裝有機會多挨兩發高瞬傷. 但是這個 build 不缺坦度, 也許是替代魯米靈藥的手段之一<br />
